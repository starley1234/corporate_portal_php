# nj503_salary — Калькулятор зарплаты — памятка для агентов

Публичный сервис N2J (группа «Бухгалтерия»): «на руки» ⇄ «до налога», НДФЛ по
прогрессивной шкале нарастающим итогом, вычеты на детей, страховые взносы
работодателя и полная стоимость сотрудника. Таблица года помесячно.

- Страница: `/salary` — состояние в адресе: `?m=gross|net&s=100000&y=2026&c=2&d=0&single=1&nr=1&sme=1&i=0.2`
- API: `POST|GET /nj503/api/calc` `{amount, mode: gross|net, year, resident, children, disabled, single, sme, injury}`
  → `{ok, result}` (деньги — в КОПЕЙКАХ); `GET /nj503/api/params` — таблица ставок по годам
- Таблиц, миграций, воркеров нет. Данные — `config/nj503_salary.php`
- Зависит от `nj501_vat` (`Service_Nj501_Vat::amount_to_kop/format_kop`). На меня планово
  опираются `nj504_vacation` (отпускные из среднего заработка) и `nj505_penalty`

## Правила для агента

- **Ставки — таблица по годам** (`config/nj503_salary.php`), не константы в коде. Новый год —
  копия блока с новыми значениями (шкала НДФЛ, вычеты, предел дохода для вычета, предельная
  база взносов — публикуется постановлением в конце октября, МРОТ) + эталонный тест в
  `tests/Unit/SalaryServiceTest.php`. `source` — реквизиты основания (показываются людям);
  не выдумывать номера документов: не знаешь — напиши только суть.
- **Расчёт — годовая проекция** (`project()`): НДФЛ с начала года минус удержанное (ст. 226 НК),
  в целых рублях (ст. 52 НК, от 50 коп. вверх). Месяц, где доход пересёк лимит вычета,
  вычета уже не получает. Не упрощать до «×0,87» — вся ценность в помесячной таблице.
- **Обратная задача** (`gross_for_net`): минимальный оклад, при котором «на руки» в ПЕРВЫЙ месяц
  равна нужной сумме до копейки. Из-за округления НДФЛ net(gross) не монотонна на ±1 ₽ —
  поэтому бинарный поиск + точный скан окрестности. Тест `test_net_to_gross_roundtrip_is_exact`.
- Взносы: единый тариф до предельной базы, сниженный сверх неё; «травматизм» — без предела;
  режим МСП — порог в МРОТ (с 2026 — 1,5, раньше — 1) и тариф сверх порога. Применимость льготы
  зависит от реестра МСП и (с 2026) от вида деятельности — страница только предупреждает.
- Не считаем: отпускные, больничные, районные коэффициенты, северные надбавки, авансы,
  профессиональные вычеты, налоговые вычеты на лечение/покупку жилья (это возврат через ФНС).
- Первый расчёт делает сервер (`NJ503_INIT` в странице), дальше JS рисует ответ API;
  зеркала формул в JS нет — истина одна, PHP.
