# JWT-декодер (модуль 620) — памятка для агентов

Разбор JWT: header, payload, claims, сроки exp/iat/nbf (без проверки подписи).

**Публичный сервис** для разработчиков и ИИ-агентов. Работает и в браузере
(локально), и через серверный JSON API — серверный прогон используется для
интеграций, агентов и контроля результатов (не позиционируется как чисто
браузерный инструмент).

## Маршруты

- Страница: `/jwt`
- API: `POST /nj620/api/decode`

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj620_*` в `classes/Service/Nj620/`.
- Точки HTTP: `/jwt` (страница) и `POST /nj620/api/decode` (JSON API).
- JS в `views/620/script.php` — зеркало сервиса; правки логики дублировать в обе стороны.
- Манифест каталога: `config/nj_module.php` (slug, группа, keywords, card_view).
