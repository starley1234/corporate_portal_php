# nj650_receipt — Чек по фото

- Страница: `/receipt` — снимок чека, разбор в фоне, результат на `/receipt/<id>`
- Что получает человек: позиции чека, сверка суммы строк с напечатанным итогом,
  траты по категориям и деление счёта на компанию (чаевые, остаток копеек)
- Деление счёта — обычная GET-форма: `/receipt/<id>?people=4&tip=10` работает
  без JavaScript, ссылку можно отправить в чат
- Создание разбора — после входа (решение владельца 06.10.2026, «как опросы»):
  гость видит плашку входа, API отвечает 401 + `login`; страница разбора —
  с прежним доступом, история «Мои чеки» следует за аккаунтом
- API: `POST /receipt/api/photo`, `GET /receipt/api/status`,
  `POST /receipt/api/photo_file` (для воркера), `POST /receipt/api/worker_result`
- Канал очереди `nj650.receipt`, воркер `workers/n2j_workers/handlers/nj650_receipt.py`
- Таблица `nj_650_runs` (чистка через 90 дней); сам кадр удаляется сразу после разбора

Инструкции для агента — см. `AGENTS.md` рядом.
