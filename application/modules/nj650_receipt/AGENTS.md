## Контракт

- Страницы: `GET /receipt` (съёмка), `GET /receipt/<id>` (разбор;
  `?people=N&tip=P` — деление счёта). Чужой разбор не показывается:
  аккаунтная запись требует тот же `user_id`, а анонимная — тот же непустой
  `visitor`; проверка выполняется до обслуживания задачи очереди.
- API (`Controller_Nj650_Api extends Controller_Vision_Base`):
  `POST /receipt/api/photo` → `{ok, run_id}`; от гостя — 401 + `login`
  (ключ `auth`, 06.10.2026); `GET /receipt/api/status?id=`;
  `POST /receipt/api/photo_file` и `POST /receipt/api/worker_result` — для
  воркера, по токену.
- Сервис `Service_Nj650_Receipt`: `shape`, `check`, `categories`, `split`,
  `number`, `money`, `items_word`, константа `CATEGORIES`.
- Таблица `nj_650_runs` (миграция `pgMigration_Nj_650_001_Receipt_Runs`).
- Конфиг `config/nj650_receipt.php`: `limits.photo_mb`, `limits.per_hour`,

## Правила для агента

- **Модель читает, сайт считает.** Это главное правило канала. Модель
  переписывает строки чека и напечатанный итог; суммы строк, сверку с итогом
  и деление счёта считает `Service_Nj650_Receipt`. Любая попытка «попросить
  модель посчитать итог» ломает сервис тихо: модель охотно подтверждает любое
  число, которое ей подсказали.
- **Не переводить и не причёсывать названия позиций.** Человек сверяет список
  с бумажным чеком глазами: «Мол. ультрапаст. 3,2%» должно остаться собой.
- Допуск сверки — 1 ₽ (копеечные округления кассы), всё крупнее показывается
  человеку как расхождение, а не прячется.
- Деление счёта раздаёт остаток копеек по одной первым участникам: сумма долей
  обязана совпадать с итогом до копейки.
- Кадр живёт на диске до конца разбора и удаляется сразу после — в базе
  остаются только числа. Не добавлять «сохранение фото чеков».
- Вся запись в БД — через `Vision`/сервис модуля; таблица только `nj_650_*`.
- Полос прогресса нет: пока идёт разбор, работает общий статус-ряд
  (`partials/live_status`) со спиннером, секундомером и этапами.
- Общий слой (`Vision`, `Controller_Vision_Base`, `photo_capture`, `vlm.py`)
  делят три сервиса — nj650, nj651, nj652. Правка там чинит или ломает все
  три сразу; специфику сервиса держать в своём модуле.
