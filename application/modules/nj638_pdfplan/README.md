# Конструктор А4 (nj638_pdfplan)

Соберите аккуратный документ А4 за минуту: шапка и дата, одна или две колонки,
подвал с нумерацией страниц. Генерация — на сервере, чистым PHP, кириллица
встраивается корректно.

## Что умеет

- **Шапка** — заголовок, подзаголовок, дата справа, разделительная линия.
- **Тело** — перенос по словам с учётом ширины шрифта, 1 или 2 колонки.
- **Подвал** — «Страница X из Y» по центру + свой текст слева.
- **Кегль** — 10 / 11 / 12 / 14.

## Безопасность

| Угроза | Мера |
|---|---|
| Command injection | shell не используется: генерация — чистый PHP |
| Переполнение | потолок текста 120 000 симв., проверка обязательных полей |
| DoS | rate limit по IP в БД (мин/час) |
| Утечка | текст обрабатывается локально, без внешних сервисов |

## Сохранение в БД

`nj_638_runs` — история генераций (title, pages, columns, сводка JSONB).

## API

```bash
curl -H 'Content-Type: application/json' \
     -d '{"title":"План","text":"Первый абзац.\n\nВторой абзац.","columns":2}' \
     /pdf-plan/api/build -o document.pdf
```
