# nj100_search — глобальный поиск платформы — памятка для агентов

Одна строка в шапке (дропдаун на каждой странице, Ctrl+K, Enter — перейти).
Ищет по 9 источникам: мои досье/компании/3D-модели/письма/AI-досье/контрагенты и
публичные база знаний, справочник организаций, вакансии.

Отдельная страница `/search` **удалена** (2026-09-26): как сервис она проигрывала
поиску в шапке, а роботы ходили по ней вариантами `?q=…&t=…`, каждый заход — девять
ILIKE-запросов. Теперь `/search` отвечает `410 Gone` без БД и шаблона (роботы
выкидывают URL из индекса), а вся выдача осталась в `/search/api`.

## Как устроено

* `Service_Nj100_Search::search($q, $user_id, $per_source, $only_types)` — по 9
  источникам (ILIKE, LIMIT на источник, общий кап, сортировка по свежести).
* `Service_Nj100_Search::sources()` — реестр типов для страницы и фильтров.
* Владельческие таблицы фильтруются по `user_id`; сбой одного источника не роняет
  остальные (warning в лог); неизвестные таблицы тихо пропускаются.
* `Controller_Nj100_Api` — `GET /search/api?q=…&types=…&per_source=…` → JSON
  `{q, results, total, sources, took_ms}`; ошибки — ЦЕЛИКОМ `{error}` с файл:строка.
* `Controller_Nj100_Search` — `/search` = `410 Gone` (страница удалена; класс
  намеренно НЕ наследует `Controller_Erp100_Base`: ни сессии, ни меню, ни БД).
* UI шапки (дропдаун, ↑↓/Enter/Esc, Ctrl+K) — инлайн в
  `application/views/template_tailwindcss.php`.

## Env

Нет собственных ключей. Рост данных → pg_trgm-индексы (см. docs/AUDIT-2026-09-21.md, P2.4).

  Ctrl+K) + JSON-выдача `/search/api`.
- Ищет по 9 источникам: 6 прежних + письма nj592, AI-досье nj598, контрагенты nj609.
- **Страница `/search` удалена** (2026-09-26, «не работает и её долбят роботы»):
  роут остался и отвечает `410 Gone` без БД и шаблона, чтобы поисковики выкинули

- Манифест оставлен: `hidden: TRUE` (нет в публичном меню и на /services для

  но никуда не ведёт «в пустоту».

## Источники (ILIKE, LIMIT на источник, общий кап из конфига)
| Таблица | Тип (`kind`) | Что | Ссылка |
|---|---|---|---|
| `nj_580_packages` | `orgdocs` | досье/пакеты организаций («мои материалы») | `/docs/<code>` |
| `nj_591_profiles` | `profile`  | карточки компаний | `/company/<code>` |
| `nj_570_models`   | `model`    | 3D-модели | `/3d/<code>` |
| `nj_560_docs`     | `kb`       | База знаний (общая) | `/kb/<slug>` |
| `nj_594_orgs`     | `org`      | Справочник организаций (общий) | `/orgs/<ogrn>` |
| `nj_550_results`  | `job`      | найденные вакансии | `/jobs/<search_id>` |
| `nj_592_letters`  | `letter`   | холодные письма (мои) | `/coldmail/<code>` |
| `nj_598_dossiers` | `dossier`  | AI-досье (мои) | `/dossier/<code>` |
| `nj_609_subjects` | `subject`  | контрагенты сторожа (мои) | `/watchdog` |

Владельческие таблицы фильтруются по `user_id`; сбой одного источника не роняет
остальные (warning в лог, результат продолжается). Источники, чья таблица ещё не
создана, тихо пропускаются.

## Классы и файлы
- `Service_Nj100_Search` — `search($q, $user_id, $per_source, $only_types)`
  + `sources()` (реестр типов) + `normalize_filter()` + `_escape_like()`.
- `Controller_Nj100_Api` — `GET /search/api?q=…&types=…&per_source=…`.
- `Controller_Nj100_Search` — `GET /search` → `410 Gone` (страница удалена).
- UI шапки (дропдаун, ↑↓/Enter/Esc, Ctrl+K, дебаунс 300 мс) — инлайн в
  `application/views/template_tailwindcss.php` (не в модуле).
- `config/nj_module.php` — манифест. Отдельного лимит-конфига нет: значения по
  умолчанию инлайн в сервисе (`per_source`=5, `total_cap`=40; `load('nj100_search')`
  вернёт NULL, ветка `$cfg ? ...` это обрабатывает).

## API
```
GET /search/api?q=…                 → JSON {q, results, total, sources, took_ms} | {error}
GET /search/api?q=…&types=org,kb    → только выбранные источники
GET /search/api?q=…&per_source=10   → больше на источник («показать ещё»)
GET /search                         → 410 Gone (страница удалена, БД не читается)
```
