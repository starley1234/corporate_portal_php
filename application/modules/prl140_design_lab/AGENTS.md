# prl140_design_lab — публичная витрина дизайна

## Состояние

Реализовано 26.10.2026: галерея и семь полноценных вариантов с темами
день/ночь и мобильными сетками проверены unit/HTTP/Chromium. Модуль ожидает
выбора владельцем направления; после выбора принципы варианта переносятся в
общую дизайн-систему отдельным этапом, а рабочий портал этой витриной не
переоформляется автоматически.

## Назначение

Изолированная витрина семи направлений оформления корпоративного портала.
Она нужна для выбора будущей дизайн-системы и не является рабочим порталом:
данные демонстрационные, операции не выполняются и ничего не сохраняется.

## Маршруты

- `/design-lab` — галерея семи вариантов.
- `/design-lab/<slug>` — полный демонстрационный портал в одном оформлении:
  `corporate`, `industrial`, `swiss`, `aurora`, `product`, `editorial`,
  `command`.
- Неизвестный slug возвращает собственную публичную 404-страницу модуля.

## Жёсткие инварианты

- Контроллер наследуется напрямую от Kohana `Controller`, не от
  `Controller_Base`.
- Не использовать `application/views/template_tailwindcss.php`, общий CSS,
  Auth, сессию, ACL и базу данных.
- Все варианты используют один `Service_Prl140_DesignLab::content()` и один
  view `views/prl140_design_lab/show.php`. Меняется только CSS.
- У галереи и каждого варианта собственный файл в `assets/design-lab/`.
  CSS встраивается контроллером в HTML; внешних `<link>` и `@import` нет.
- Каждый CSS обязан определять `html[data-theme="dark"]`, мобильные
  breakpoint'ы 760/520 px, открытое состояние меню
  `html[data-menu-open="true"] .dl-primary-nav` и
  `prefers-reduced-motion`.
- Ответы всегда `noindex`, `Cache-Control: no-store` и без cookie. Ссылки
  содержат `v=<revision>`, где revision считается из хэшей контроллера,
  сервиса, views и всех CSS.
- Тема выбирается по приоритету: валидный `?theme=light|dark`,
  `localStorage`, затем `prefers-color-scheme`. Невалидная тема не отражается
  в HTML.

## Изменение вариантов

- Метаданные и порядок: `config/prl140_design_lab.php`.
- Общее демонстрационное содержание: `Service_Prl140_DesignLab`.
- Семантические классы имеют префикс `dl-`; не добавляйте общие `.prl-*`
  классы рабочего портала.
- Если добавляется вариант, нужен новый автономный CSS, карточка галереи
  появится из конфига автоматически, а список slug в `DesignLabTest` и
  `tests/http_smoke.py` нужно расширить.

## Проверки

- `bash bin/test DesignLabTest` — реестр, прямой контроллер, одинаковое
  содержание, темы, 404, антикэш, автономность и responsive-контракт CSS.
- `tests/http_smoke.py` анонимно проходит галерею, все семь вариантов в
  тёмной теме и неизвестный slug до логина.
