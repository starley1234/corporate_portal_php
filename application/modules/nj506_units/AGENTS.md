# nj506_units — конвертер единиц — памятка агенту

Публичный stateless-сервис `/units`: единицы длины, массы, объёма, площади, скорости, температуры и давления; рядом с метрическими представлены традиционные русские меры.

## Контракт
- `Service_Nj506_Units::calculate(category, value, from, to)` — PHP-истина; `catalog()` отдаёт данные UI и JS.
- Коэффициенты, названия, быстрые примеры и оговорки — `config/nj506_units.php`; не дублировать справочник во вьюхе.
- API: `POST /nj506/api/calc`, `GET /nj506/api/catalog`; данные не сохраняются.
- Страница `/units`, query-share: `?c=area&v=1&from=ha&to=are`.
- Преобразование `base = value * factor + offset` поддерживает температуру; для иных размерностей используется `offset = 0`.

## Правила
- Отрицательные длина/масса/объём/площадь отвергаются; температура проверяется на абсолютный ноль.
- Меняя справочник, держать тесты `tests/Unit/UnitsServiceTest.php` и JS-паритет `tests/Js/units_parity.mjs` в актуальном состоянии.
- Сотка — ровно 100 м²; пуд, аршин/сажень/верста и ведро помечать как исторические/условные там, где существовали варианты.
- Никаких таблиц, очередей, пользовательской истории или внешних API.
