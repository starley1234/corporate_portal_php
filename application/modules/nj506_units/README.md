# Конвертер единиц (`nj506_units`)

`/units` переводит длину, массу, объём, площадь, скорость, температуру и давление; метрические, английские и русские бытовые меры собраны в `config/nj506_units.php`.

- Страница: `/units`; состояние расчёта хранится в параметрах ссылки.
- API: `POST /nj506/api/calc` (`category`, `value`, `from`, `to`), справочник — `GET /nj506/api/catalog`.
- Stateless: база данных, фоновые задачи и сохранение пользовательского ввода не используются.
- Формулы и справочник: `Service_Nj506_Units`; клиентский расчёт получает справочник той же конфигурации.

Исторические меры имеют варианты по месту и эпохе. Для «ведра» отдельно указаны условные 10 л и исторические 12,3 л; это справочные эквиваленты, а не универсальные стандарты.
