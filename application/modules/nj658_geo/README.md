# nj658_geo — справочник населённых пунктов России

Единый справочник городов и посёлков для сервисов платформы: подсказки в
формах, фильтры по регионам, геопривязка записей.

- **Данные:** 2020 населённых пунктов, 82 региона (источник —
  `source_data/0_loc_rus.sql`, сид миграции 001 идемпотентен по slug).
- **Публичные страницы:** `/geo` — список с поиском и фильтром;
  `/geo/<slug>` — карточка населённого пункта.
- **JSON-API:** `GET /geo/api/suggest?q=моск&limit=10` — подсказки для
  автодополнения (крупные города первыми); `GET /geo/api/regions` — регионы
  с количеством записей.
- **Админка:** `/geo/admin` (право `nj658.admin`): поиск, правка, добавление,
  скрытие, удаление, CSV-экспорт.
- **PHP API:** `Service_Nj658_Geo::search() / city() / regions() / by_region()
  / label()` — лаконичный слой для других модулей (вакансии по городам и т.п.).

Подробности — в [AGENTS.md](AGENTS.md).
