# nj658_geo — справочник населённых пунктов России

## Состояние работ
- **06.10.2026:** модуль собран из дампа `source_data/0_loc_rus.sql` (2020
  записей, 82 региона, phpMyAdmin-экспорт справочника старого проекта).
  Миграция 001 создаёт таблицу `nj_658_cities` и сеет данные идемпотентно
  (ON CONFLICT по slug — повторный прогон не затирает ручные правки).
- Публичные страницы: `/geo` (список с поиском и фильтром по региону) и
  `/geo/<slug>` (страница населённого пункта). JSON-API для форм других
  модулей: `/geo/api/suggest`, `/geo/api/regions`.
- Админка: `/geo/admin` (право `nj658.admin`) — поиск, правка, добавление,
  скрытие, удаление, CSV-экспорт.
- Сид хранится в `migrations_pg/data/nj658_cities_seed.sql` (473 КБ, 9 батчей
  по 250 строк) — файл именно ДАННЫХ, не код: правится генератором, не руками.

## Назначение
Единый справочник городов/сёл/посёлков для всех сервисов платформы, которым
нужен список населённых пунктов: подсказки в формах («вакансии по городам»),
фильтры, геопривязка. Модуль не знает о потребителях — потребители зовут его.

## Ключевые классы
| Класс | Роль |
|---|---|
| `Service_Nj658_Geo` | всё API: чистые функции (нормализация, slug, label, CSV) + запросы к БД |
| `Controller_Nj658_Geo` | публичные страницы `/geo`, `/geo/<slug>` |
| `Controller_Nj658_Api` | JSON: `/geo/api/suggest?q=…&limit=…`, `/geo/api/regions` |
| `Controller_Nj658_Admin` | админка `/geo/admin` (право `nj658.admin`) |

## API для других модулей
```php
Service_Nj658_Geo::search('моск', 10);   // подсказки: prefix LIKE, крупные первыми
Service_Nj658_Geo::city('abakan');       // запись по slug ИЛИ id
Service_Nj658_Geo::regions();            // [ ['title' => '…', 'cities' => N], … ]
Service_Nj658_Geo::by_region('Красноярский край');
Service_Nj658_Geo::label($row);          // «Абан · Красноярский край»
```
HTTP-вариант тех же подсказок: `GET /geo/api/suggest?q=абак&limit=15`
(limit 1..25, из конфига). Поиск понимает «ё»/«е» и регистр — нормализация
одинаковая на обеих сторонах (`normalize_query`).

## Таблица nj_658_cities
`id` BIGSERIAL PK · `slug` UNIQUE · `title` · `title_norm` (lower, ё→е — ключ
поиска) · `title_full` · `name_latin` · `region` · `district` · `kind` (белый
список из конфига: город/село/поселок/пгт/…) · `population` · `is_dup`
(одноимённые пункты) · `lat`/`lon` NUMERIC(9,6) · `is_active` · `source`
(`seed`|`manual`) · `created_at`/`updated_at`. Индексы: `title_norm` prefix,
`region`, `population DESC`.

## Правила
- Поиск — всегда через `title_norm` (нормализованный), вывод — `title`.
- Виды населённых пунктов — только из `config/nj658_geo.php` (`kinds`):
  расширяется правкой конфига, а не миграцией.
- Сид идемпотентен: ручные правки в админке (`source='manual'`) повторный
  `db:migrate` не затирает.
- Внешних хостов и скриптов в модуле нет; вёрстка — общий Tailwind.
