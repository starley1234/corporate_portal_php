# nj502_words — Сумма прописью — памятка для агентов

Публичный сервис N2J: сумма прописью для договоров, платёжек и счетов (Number 2 Words).

- Страница: `/summa-propisyu` (share-ссылки `?a=22122&u=1&k=1`)
- API: `POST /nj502/api/convert` (JSON, публичный)
- Таблиц/воркеров нет; алгоритм — `Service_Nj502_Words` (до 999 млрд ₽)
- JS в браузере — зеркало сервиса для мгновенного пересчёта

## Правила для агента

Второй публичный сервис N2J (финансы, аудитория — бухгалтера и юристы). Stateless: **без БД, без воркеров.**

## Контракт
- Класс-истина: `Service_Nj502_Words` (число → русская прописи; рубли словами, копейки цифрами или словами).
- Страница: `Controller_Nj502_Words` → `/summa-propisyu` (share-URL `?a=22122&u=1&k=1`).
- API: `Controller_Nj502_Api` → `POST /nj502/api/convert` `{amount, ucfirst, kopecks_words}`.
- Диапазон: до 999 999 999 999 руб. Парсер сумм — копия из nj501 (намеренно: модули изолированы).
- JS-зеркало: `views/502/script.php` (инлайн, подключается в конце вьюхи).
  **При изменении алгоритма менять PHP и JS вместе**, тесты `tests/Unit/WordsServiceTest.php`
  (векторы: «одна тысяча», 11–14 → «копеек», 21 копейка — женские формы тысяч).

## Известные грабли (уже решены, не сломать)
- 11–19: индекс в TEENS — `g%100 - 10`, а не `g%100`.
- Существительное «рубль» добавляется **один раз** после всех триад, не в цикле.
- Нулевые триады (1 000 000) пропускаются, но их старшие соседи остаются («один миллион», не «один миллион ноль»).

## Не делать
- Таблицы/воркеры не добавлять; историю не хранить даже в localStorage.
- Не редактировать `modules/`, `system/`; статику внутрь модуля не класть (инлайн — исключение).
