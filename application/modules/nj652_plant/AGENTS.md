## Правила для агента

- **Про съедобность сервис не отвечает — никогда.** Ни «можно ли съесть эту
  ягоду», ни определение грибов: у съедобных видов есть ядовитые двойники,
  которые по фотографии не отличить, а цена ошибки — жизнь. Запрет прописан в
  промпте воркера и в тексте страницы; снимать его нельзя.
- **Даты считает сайт, а не модель.** Модель даёт интервалы в днях,
  `schedule()` превращает их в календарь: шаг полива выбирается по месяцу
  КАЖДОЙ даты (план из октября сам растягивается к декабрю), а подкормки в
  зимние месяцы пропускаются. Просить у модели готовые даты бессмысленно — она
  не знает сегодняшнего числа.
- **Низкую уверенность показываем честно.** При `confidence < 55` страница
  прямо просит переснять и сверяться со справочником: лечить не то растение
  хуже, чем не определить его.
- Пометка `toxic_pets` — предупреждение для хозяев кошек и собак, не
  справочная истина; формулировка должна оставаться осторожной.
- Кадр удаляется сразу после разбора, в базе — только разбор.
- Вся запись в БД — через `Vision`/сервис модуля; таблица только `nj_652_*`.
- Полос прогресса нет: пока идёт разбор, работает общий статус-ряд
  (`partials/live_status`).
- Общий слой делят nj650, nj651 и nj652: правка там затрагивает все три.
