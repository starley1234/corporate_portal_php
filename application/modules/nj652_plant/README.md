# nj652_plant — Растение по фото

- Страница: `/plant` — снимок растения, разбор в фоне, результат на `/plant/<id>`
- Что получает человек: вид (русское и латинское название, уверенность), что
  видно на фото (пятна, вредители, перелив), список действий и условия ухода
- Календарь полива и подкормок на месяц строит сайт: зимой полив реже,
  подкормки в зимние месяцы не назначаются
- Создание разбора — после входа (решение владельца 06.10.2026, «как опросы»):
  гость видит плашку входа, API отвечает 401 + `login`; страница разбора —
  с прежним доступом, история следует за аккаунтом
- API: `POST /plant/api/photo`, `GET /plant/api/status`,
  `POST /plant/api/photo_file` (для воркера), `POST /plant/api/worker_result`
- Канал очереди `nj652.plant`, воркер `workers/n2j_workers/handlers/nj652_plant.py`
- Таблица `nj_652_runs` (чистка через 90 дней); сам кадр удаляется сразу после разбора
- Сервис намеренно не отвечает на вопрос о съедобности растений и грибов

Инструкции для агента — см. `AGENTS.md` рядом.
