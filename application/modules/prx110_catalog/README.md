# prx110_catalog — Каталог сервисов

Реестр prx-модулей: манифест `config/prx_module.php` в каждом модуле попадает
в каталог и поиск с учётом аудитории, может дать карточку главной и чипы шапки.
В постоянной панели остаётся «Все сервисы», остальные ссылки пользователь
добавляет в Избранное своего аккаунта.

При обновлении примените `bin/console db:migrate`: миграция prx110 создаёт
таблицу закладок. Старые браузерные звёзды предлагается перенести отдельно и
только с подтверждением. См. `AGENTS.md` — там контракт API и шаблон манифеста.
