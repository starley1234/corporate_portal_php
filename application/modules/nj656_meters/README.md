# Показания счётчиков (NJ-656)

`/meters` — личный журнал показаний воды, электричества, тепла и других измеряемых коммунальных услуг. Это не одноразовый калькулятор: сервис хранит последовательность реальных показаний и рассчитывает расход **между двумя конкретными датами**, стоимость по тарифу на дату нового показания, средний темп и ориентир на 30,4 дня.

## Зачем здесь база, а не ответ ИИ

ИИ может объяснить, как вычесть два числа, но не заменяет:

- приватную, связанную с конкретным браузером историю измерений;
- сохранённый для каждого периода тариф — смена тарифа не переписывает прошлое;
- сравнение нового темпа с тремя прошлыми периодами и сигнал о скачке;
- экспорт накопленной пользователем истории в CSV.

## Приватность

Сервис не запрашивает и не добавляет отдельных полей адреса, номера квартиры, имени или IP-адреса. Хранятся только введённые пользователем название, единица, тариф, добровольный месячный ориентир и показания. Владелец определяется общей технической cookie `Visitor::uid()`; если cookie нельзя поставить, запись запрещена, чтобы данные не стали общими. Удаление счётчика каскадно удаляет всю его историю.

## Данные и маршруты

- `nj_656_meters` — счётчики владельца (`code`, `owner_key`, название, единица, текущий тариф и ориентир).
- `nj_656_readings` — точки истории; уникальны по паре `meter_id + reading_on`, цена тарифа фиксируется на точке.
- `GET|POST /meters` — список и создание журнала.
- `GET /meters/<code>` — личный дашборд.
- `POST /meters/<code>/reading|settings|delete` — изменение с CSRF.
- `GET /meters/<code>/export` — CSV только для владельца.

Миграция: `pgMigration_Nj_656_001_Meters_CreateTables`.

## Формула

Для каждой пары показаний `A → B`:

```text
расход = B.показание − A.показание
средний темп = расход / число календарных дней
стоимость = расход × тариф, сохранённый с B
прогноз на месяц = средний темп × 30,4375 × тариф
```

Новая дата обязана быть позже предыдущей, а новое показание — не меньше старого. После замены прибора создайте новый журнал: попытка «обнулить» старый намеренно отклоняется, чтобы не получить отрицательный расход.
