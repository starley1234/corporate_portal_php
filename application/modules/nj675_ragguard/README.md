# NJ-675 RAG Guard

`/ragguard` проверяет вручную переданный набор уже извлечённых RAG-документов:
ожидаемый tenant, текст, метку доверия. Локальные правила ищут несовпадение tenant,
фразы prompt injection и шаблоны токенов, карт и email. Ни LLM, ни хранилище,
ни URL источников не вызываются; исходный текст и совпадения не возвращаются.

Это preflight-инспектор контекста, не динамический тест retrieval/ACL и не
подтверждение безопасности всей RAG-системы. Метка `trusted` — только входная
метка оператора, не доказательство доверия к источнику. Динамический этап должен
проверять авторизованный sandbox retrieval, подмену tenant и поведение модели на
синтетических canary-документах; он пока намеренно не отправляет запросы к цели.
Проверка:
`.tools/nj675_ragguard_stand.php` через `phpwasm_stand.mjs`.
