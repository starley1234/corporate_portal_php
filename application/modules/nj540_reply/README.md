# Отзыв 2 Ответ (nj540_reply)

**Review 2 Reply** — вставьте отзыв клиента, получите готовый публичный ответ:
ИИ определяет тональность и темы, предупреждает об эскалациях, пишет в выбранном
тоне (дружелюбный / официальный / краткий / с извинением / премиальный).

## Зачем

На отзывы маркетплейсов и карт нужно отвечать быстро и лично. Это долго.
Здесь — полминуты: отзыв в форму → задача уходит в очередь фоновых воркеров →
LangChain-конвейер (анализ → ответ) → готовый текст, который можно скопировать
или переписать другим тоном.

## Как устроено

| Слой | Что |
|---|---|
| `Controller_Nj540_Review` | `/review` — форма/создание, `/review/<code>` — статус и результат |
| `Controller_Nj540_Api` | JSON: `GET status/<code>`, `POST regen/<code>` (CSRF) |
| `Service_Nj540_Reply` | валидация, лимиты по IP (6/час, 25/день), очередь, reconcile |
| воркер `nj540.reply` | LangChain LCEL: анализ отзыва (JSON) → генерация ответа |
| `nj_540_replies` | отзыв, статус, ответ, разбор (JSONB), история версий в `meta` |

## Настройки

`config/nj540_reply.php`: лимиты запросов (по умолчанию 15/час, 25/день с одного IP),
длины текста, параметры задачи очереди, набор тонов. Меняется без правки кода.

## Запуск

Требования: применена миграция 001 (`bin/console db:migrate`), воркеры запущены
(`python -m n2j_workers`), в `workers/.env` настроен LLM-шлюз
(`TOOLFORGE_API_URL`, опционально `NJ540_MODEL`).

    /review  →  вставить отзыв  →  /review/<code>  →  ответ через 10–30 секунд

## API

    GET /nj540/api/status/<code>
      → {"ok":true,"status":"new|done|error","reply":"...","analysis":{...},"error":null}

    POST /nj540/api/regen/<code>   (csrf, затем redirect 303 на /review/<code>)
