# ldap_auth — необязательный LDAP-драйвер

## Состояние

Реализован; проверен на мок-стенде. Реальный LDAP и Docker-сборку проверить
в целевом окружении.

`PRX_LDAP_ENABLED=1` подключает библиотеку и выбирает `Auth_Ldap`; по умолчанию
работает ORM. Подробная инструкция: `application/modules/ldap_auth/README.md`.
LDAP проверяет пароль только существующего локального пользователя с ролью
login; роли и TOTP остаются в портале. Автосоздания, LDAP-групп и fallback на
локальные пароли нет. Только LDAPS или StartTLS, проверка сертификата обязательна,
сервисный bind без пустого пароля, экранированный фильтр и ровно одна запись.
Запомненные ORM-cookie в LDAP-режиме не используются. Тест:
`php .tools/ldap_auth_stand.php`; Docker-extension собирается с build-arg
`INSTALL_LDAP=1`; требуется также реальный LDAP/FPM/БД стенд.
