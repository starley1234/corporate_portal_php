# Тест regex (модуль 622) — памятка для агентов

Офлайн-прогон регулярного выражения (PCRE) на сервере: совпадения, группы, замена.

**Публичный сервис** для разработчиков и ИИ-агентов. Работает и в браузере
(локально), и через серверный JSON API — серверный прогон используется для
интеграций, агентов и контроля результатов (не позиционируется как чисто
браузерный инструмент).

## Маршруты

- Страница: `/regex`
- API: `POST /nj622/api/test`

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj622_*` в `classes/Service/Nj622/`.
- Точки HTTP: `/regex` (страница) и `POST /nj622/api/test` (JSON API).
- JS в `views/622/script.php` — зеркало сервиса; правки логики дублировать в обе стороны.
- Манифест каталога: `config/nj_module.php` (slug, группа, keywords, card_view).
