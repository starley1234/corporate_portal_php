# nj513_datewords — дата прописью — памятка агенту

Публичный stateless-сервис `/date-words`: форматы даты для договоров, приказов и актов; длинный текст, `«ДД» месяц YYYY г.`, числовой вариант и диапазон дат.

## Контракт
- `Service_Nj513_Datewords::parse_date()`, `::day_words()`, `::year_words()`, `::convert()`, `::range()` — PHP-истина.
- API: `POST /nj513/api/convert` `{date, end?}`; принимает ISO `YYYY-MM-DD` и `DD.MM.YYYY`.
- Валидация — календарная, через `checkdate`; год ограничен 0001–9999.
- В диапазоне одного месяца используется «с первого по пятое сентября…»; на границе месяца обе даты записываются полностью.
- URL: `/date-words?date=2026-09-01&end=2026-09-30`.
