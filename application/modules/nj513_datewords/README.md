# Дата прописью (`nj513_datewords`)

`/date-words` превращает ISO-дату или ДД.ММ.ГГГГ в запись словами, «ДД» месяц YYYY г. и ДД.ММ.ГГГГ; поддерживает диапазон дат в одном месяце и между месяцами.

- Бизнес-логика: `Service_Nj513_Datewords`; API `POST /nj513/api/convert`.
- Интерфейс интерактивен и сохраняет только share-параметры в URL; база и история отсутствуют.
- Подходит для подготовки черновика документа; окончательный формат и падеж нужно сверять с требованиями конкретного документа.
