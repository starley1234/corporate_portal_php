# IP и подсети (модуль 630) — памятка для агентов

IPv4-калькулятор: по записи a.b.c.d/n считает адрес сети, broadcast, маску,
wildcard, первый/последний хост и число адресов, определяет класс и приватность.

- Страница: `/ipcalc`
- API: `GET /nj630/api/range?value=10.0.0.0/16`

Без таблиц и очередей. Вся арифметика — целочисленная (32 бита);
логика — в `classes/Service/Nj630/Ipcalc.php`, JS — зеркало в `views/630/script.php`.

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj630_Ipcalc` (`parse`, `report`, `in_subnet`).
- Точки HTTP: `/ipcalc` (страница), `GET /nj630/api/range`.
- Только IPv4/CIDR; /31 и /32 обрабатываются особым порядком (хостов 0).
- JS в `views/630/script.php` — зеркало (uint32-арифметика через >>> 0).
- Манифест: `config/nj_module.php` (slug `ipcalc`, группа «Разработчику»).
