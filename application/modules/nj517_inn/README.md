# Проверка ИНН

`/inn` локально проверяет длину и контрольные цифры ИНН. Формат номера: 10
цифр для юридического лица, 12 — для физического лица/ИП. Успешная проверка
не доказывает, что номер присвоен или организация продолжает работать.

По отдельной кнопке можно запросить открытую карточку ФНС для 10-значного ИНН
организации. Запрос ограничивается и сохраняется общим модулем `nj594_orgregistry`;
найденная открытая карточка попадает в справочник организаций. 12-значные номера
проверяются только в браузере и никуда не отправляются. ИНН не записывается в
адрес страницы или хранилище браузера.

- Сервис: `Service_Nj517_Inn::validate()` и `::lookup()`.
- API: `POST /nj517/api/lookup` (CSRF; только явный поиск организации).
- Данные: собственной БД/миграций нет; владелец сведений — `nj594_orgregistry`.
- Проверка: `php tests/mini_runner.php InnService`; `tests/Js/inn_privacy.mjs`.
- Формат (10 цифр у юрлица, 12 у физлица) сверяется с [ФНС России](https://www.nalog.gov.ru/rn77/terms/7756931/); контрольные цифры использует общий сервис `nj594_orgregistry`.
