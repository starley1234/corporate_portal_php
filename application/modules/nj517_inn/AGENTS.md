# nj517_inn — проверка ИНН — памятка для агентов

Публичная страница `/inn`: локальная проверка формата/контрольных цифр и отдельный
запрос открытых сведений по ИНН организации. Мостик из бесплатной проверки в
справочник компаний N2J.

## Состояние работ

- 02.10.2026: модуль создан по PLAN-2026-10-01, волна 3. PHP-сервис использует
  единый алгоритм `Service_Nj594_Orgs::inn_valid`; зеркальная проверка в JS не
  отправляет номер на сервер и не пишет его в URL/localStorage.
- Онлайн-запрос запускается только отдельной кнопкой и только для 10-значного
  ИНН организации; используется `Service_Nj594_Orgs::refresh()` с его лимитами
  ФНС и сохранением найденной открытой карточки в `nj_594_orgs`.
- 12-значный ИНН физлица/ИП проверяется только локально; автоматический запрос
  запрещён. UI заранее объясняет отправку/сохранение перед кнопкой запроса.
- Тесты: `php tests/mini_runner.php InnService`; HTTP smoke — `/inn` и отказ GET
  для API; браузерный сценарий — `tests/Js/inn_privacy.mjs` (нужен jsdom).

## API и данные

- `POST /nj517/api/lookup` — form `{csrf, inn}` → `{ok, result:{check, card}}`;
  ошибки: HTTP 400 (формат/контрольные цифры), 403 (CSRF), 422 (12 цифр),
  429 (лимит ФНС), 503 (ФНС/справочник недоступны).
- Только онлайн-запрос передаёт 10-значный ИНН в backend и далее в открытый
  сервис ФНС. Карточка из ФНС сохраняется владельцем `nj594_orgregistry`;
  сырые данные пользовательского ввода не сохраняются новым модулем.
- Собственной таблицы и миграций нет. Зависимость: `Service_Nj594_Orgs`.

## Правила для агента

- Не превращать локальную проверку в автозапрос и не класть ИНН в query/hash,
  cookies или localStorage.
- Не отправлять 12-значный ИНН в ФНС. Если меняется политика, сначала обновить
  раскрытие рядом с действием и памятку о том, что именно передаётся/сохраняется.
- Новый путь/карточку регистрировать в манифесте; состав `/s/company` — в конфиге
  `nj611_landing`, а не копировать тексты в контроллер.
- При изменении алгоритма сверять PHP с `Service_Nj594_Orgs::inn_valid()` и
  прогонять unit/UI проверки. Не создавать второй источник истины по ФНС.
