# PostgreSQL_PDO — альтернативный драйвер

Не подключён по умолчанию: используется PostgreSQL/ext-pgsql.
Не включать одновременно с PostgreSQL: оба объявляют Database_PostgreSQL.
При переходе на PDO нужны отдельные проверки RETURNING и типов результатов.


## Состояние
- Готовность: **запасной**, не подключён; включать только вместо PostgreSQL и после отдельных проверок.
