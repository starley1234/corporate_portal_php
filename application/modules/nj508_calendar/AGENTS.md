# nj508_calendar — Календарь и даты — памятка для агентов

Публичный сервис N2J (группа «Даты и время»): производственный календарь РФ,
рабочие дни/часы между датами, «сколько дней до…», точный возраст и стаж
(ст. 192 ГК РФ), «прибавить N дней» (календарных или рабочих).

- Страницы: `/calendar` (вкладки `?m=year|between|until|age|add` + поля формы в URL),
  `/calendar/<год>` — отдельный адрес для поисковиков (нет года → 404)
- API: `POST|GET /nj508/api/calc` `{mode: between|until|age|add, …}`,
  `GET /nj508/api/year?year=2026`, `GET /nj508/api/info`
- Таблиц, миграций, воркеров нет. Данные года — `config/nj508_calendar.php`
- Зависимости от модулей: нет. На меня опираются (план): `nj504_vacation`
  (`Service_Nj508_Calendar::month_summary()`, `between()`)

## Правила для агента

- **Календарь — таблица, не формула.** Переносы выходных каждый год утверждает
  Правительство (обычно в сентябре–октябре). Новый год = новый блок в конфиге:
  `off` (будни-нерабочие с названием), `work` (рабочие сб/вс), `short`
  (сокращённые дни), `source` (реквизиты постановления).
  **Новый год обязан получить эталонную строку в `tests/Unit/CalendarServiceTest.php`
  (`$_golden`: рабочих дней, часов, сокращённых)** — сверять с официальным календарём.
- **Нет года — нет молчаливого расчёта.** Сервис отвечает `error=no_calendar` (HTTP 422)
  и пишет `Log::WARNING` администратору; приблизительный расчёт по сб/вс
  возможен только по явному `approx=1` и помечается `approx=true`.
  Не «улучшать» это поведение подстановкой прошлого года.
- Период «годы/месяцы/дни» — `period()`: от исходного числа, обрезка по концу месяца
  (29 февраля → 28 февраля). Не использовать `DateTime::diff` — он считает иначе.
- Даты — строки `YYYY-MM-DD` / `DD.MM.YYYY`, UTC, диапазон 1900–2100.
- «Сегодня» для `until` приходит из браузера (`today`), чтобы не врать в часовом поясе
  пользователя; сервер по умолчанию берёт `date('Y-m-d')`.
- Манифест несёт `sitemap` — дополнительные адреса страниц годов для `sitemap.xml`
  (собирает `nj602_content`). Добавил год в конфиг — добавь его адрес в манифест.
- Вкладка «Календарь года» рендерится на сервере (SEO), остальные — JS поверх API
  (зеркала формул в JS нет: истина одна — PHP).
