# JSON-инструмент (модуль 614) — памятка для агентов

Форматирование, валидация, минификация и статистика JSON с серверной локализацией ошибок.

**Публичный сервис** для разработчиков и ИИ-агентов. Работает и в браузере
(локально), и через серверный JSON API — серверный прогон используется для
интеграций, агентов и контроля результатов (не позиционируется как чисто
браузерный инструмент).

## Маршруты

- Страница: `/json`
- API: `POST /nj614/api/format, POST /nj614/api/validate`

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj614_*` в `classes/Service/Nj614/`.
- Точки HTTP: `/json` (страница) и `POST /nj614/api/format, POST /nj614/api/validate` (JSON API).
- JS в `views/614/script.php` — зеркало сервиса; правки логики дублировать в обе стороны.
- Манифест каталога: `config/nj_module.php` (slug, группа, keywords, card_view).
