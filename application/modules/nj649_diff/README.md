# nj649_diff — Сравнение текстов

- Страница: `/diff` — две версии рядом, отличия построчно и по словам
- Параметры: не различать регистр, игнорировать пробелы, пропускать пустые строки, подсветка слов
- Сводка: добавлено / удалено / изменено строк и похожесть в процентах
- Результат можно забрать как unified diff (формат заплаток git)
- API: `POST /nj649/api/compare` (`rows=1` — построчный разбор)
- Таблиц и очередей нет: тексты не сохраняются

Инструкции для агента — см. `AGENTS.md` рядом.
