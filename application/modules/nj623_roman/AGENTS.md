# Римские числа (модуль 623) — памятка для агентов

Перевод арабских чисел (1–3999) в римскую запись и обратно, с автоопределением
направления по вводу. Неверная римская запись честно отклоняется.

**Маршруты**

- Страница: `/roman`
- API: `GET /nj623/api/convert?value=1987`

**Структура**

- `classes/Service/Nj623/Roman.php` — бизнес-логика (чистые функции, stateless)
- `classes/Controller/Nj623/*` — страница + JSON API
- `views/623/index.php`, `views/623/script.php` — интерфейс и JS-зеркало
- `views/nj623/card.php` — виджет главной
- `config/nj_module.php` — манифест для каталога nj110_catalog

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj623_Roman` (`to_roman`, `from_roman`, `convert`).
- Точки HTTP: `/roman` (страница) и `GET /nj623/api/convert` (JSON API).
- Диапазон 1–3999; строгая проверка записи (regex) — неверную строку НЕ «угадывать».
- JS в `views/623/script.php` — зеркало сервиса; правки логики дублировать в обе стороны.
- Манифест каталога: `config/nj_module.php` (slug `roman`, группа «Конвертеры»).
