# PDF-инструменты (nj634_pdf)

Легковесные утилиты для работы с PDF — без установки программ, без внешних
бинарников: всё выполняется на сервере чистым PHP (zlib/mbstring/fileinfo).

## Что умеет

- **Данные файла** — версия PDF, число страниц, метаданные, шифрование, размер.
- **Извлечение текста** — текстовый слой PDF (сканы без OCR не читаются).
- **Текст → PDF** — страница A4 с кириллицей (встраиваемый шрифт DejaVu Sans).
- **Вырезать страницы** — диапазон страниц в отдельный файл.
- **Перекомпоновать** — страницы одного файла в любом порядке, с повторами.
- **Объединить файлы** — несколько PDF в один: все страницы по порядку.

## Безопасность

| Угроза | Мера |
|---|---|
| Command injection | shell не используется вообще: разбор/генерация — чистый PHP |
| Загрузка мусора | проверка `is_uploaded_file`, магия `%PDF-`, лимит 15 МБ, отказ от шифрованных файлов |
| DoS | rate limit по IP в БД (мин/час), потолок сохраняемого текста 200 000 симв. |
| Утечка | файлы не покидают сервер, не публикуются; в историю пишется сводка (+ текст только по запросу «Текст») |

## Сохранение в БД

`nj_634_runs` — история операций (сводка JSONB, извлечённый текст для
копирования). Чистка старых записей — через `/nj100/cleanup` (`nj634_runs`).

## Как проверять

```bash
# данные файла
curl -F 'file=@document.pdf' /pdf/api/info
# извлечение текста
curl -F 'file=@document.pdf' /pdf/api/text
# текст → PDF
curl -H 'Content-Type: application/json' -d '{"title":"T","text":"Привет"}' /pdf/api/txt2pdf -o out.pdf
# страницы 2–4
curl -F 'file=@document.pdf' -F 'first=2' -F 'last=4' /pdf/api/split -o pages.pdf
# объединить несколько файлов
curl -F 'files[]=@a.pdf' -F 'files[]=@b.pdf' /pdf/api/mergefiles -o merged.pdf
```
