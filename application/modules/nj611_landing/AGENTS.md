# Сервисы по задачам (nj611_landing) — памятка для агентов

Посадочные страницы групп сервисов — вместо списка инструментов показываем
задачу целиком:

- `/s` — каталог групп («найти клиентов», «проверить компанию», «контент»…);
- `/s/<slug>` — лендинг группы: одно обещание, быстрый старт с автоподстановкой
  в форму целевого сервиса, «как это работает» в 3 шага, цифры и FAQ.

Быстрый старт заполняет форму нужного сервиса (префиллы передаёт целевая
страница) — пользователь попадает сразу к делу, а не на список кнопок.

## Как это устроено

Тексты и состав групп лежат целиком в `config/nj611_landing.php`; сервис
склеивает их с манифестами каталога (nj110) и отбрасывает не подключённые
модули — группа никогда не показывает «мёртвую» ссылку.

## Правило живости групп
- Группа показывается, **только если** заполнен быстрый старт и все модули группы
  реально подключены (`Service_Nj611_Landing::groups()` отбрасывает не
  подключённые slug'и). Пустых страниц в каталоге быть не должно.
- `extras` (служебные страницы: новости, справка) отбрасываются так же.

## Классы и файлы
- `Service_Nj611_Landing` — `groups()`, `group(slug)`, `extras()` (склейка конфига
  с манифестами каталога).
- `Controller_Nj611_Landing` — `action_index` (/s), `action_group` (/s/<slug>).
- `views/611/{index,landing,card}.php`.
- `config/nj611_landing.php` — все тексты, группы, быстрый старт, FAQ.
- `config/nj_module.php` — манифест (`header_chips: FALSE` — навигация внутри страницы).

## Конвенции
- `header_chips => FALSE`: чипы раздела в шапке не рисуются — группы с
  горизонтальной прокруткой выглядят плохо, навигация уже внутри лендинга.
- SEO: title/h1 полные русские `seo_title`/`seo_description` из конфига.
- Ссылки на внешние ресурсы — всегда со схемой (`https://…`).

## Правки
- Добавить группу = дописать ключ в `config/nj611_landing.php` (слаги модулей
  должны совпадать со слагами их манифестов) + при необходимости чип в
  `header_nav` каталога.
- Менять тексты — только в конфиге, не в view.
