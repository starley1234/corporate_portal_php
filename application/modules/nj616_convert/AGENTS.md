# Кодировщик (модуль 616) — памятка для агентов

Base64 (UTF-8) и URL encode/decode: живое преобразование в браузере + серверный API.

**Публичный сервис** для разработчиков и ИИ-агентов. Работает и в браузере
(локально), и через серверный JSON API — серверный прогон используется для
интеграций, агентов и контроля результатов (не позиционируется как чисто
браузерный инструмент).

## Маршруты

- Страница: `/convert`
- API: `POST /nj616/api/convert`

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj616_*` в `classes/Service/Nj616/`.
- Точки HTTP: `/convert` (страница) и `POST /nj616/api/convert` (JSON API).
- JS в `views/616/script.php` — зеркало сервиса; правки логики дублировать в обе стороны.
- Манифест каталога: `config/nj_module.php` (slug, группа, keywords, card_view).
