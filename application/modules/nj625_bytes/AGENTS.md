# Единицы информации (модуль 625) — памятка для агентов

Перевод битов, байтов и кратных единиц по обеим шкалам: двоичной
(КиБ/МиБ/ГиБ/ТиБ, шаг 1024) и десятичной (КБ/МБ/ГБ/ТБ, шаг 1000).
Понятный для человека формат плюс полная таблица.

- Страница: `/bytes`
- API: `GET /nj625/api/convert?value=500MB`

Без таблиц и очередей. Внутренняя валюта — байты; логика — в
`classes/Service/Nj625/Bytes.php`, JS — зеркало в `views/625/script.php`.

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj625_Bytes` (`units`, `parse`, `table`, `human`).
- Точки HTTP: `/bytes` (страница), `GET /nj625/api/convert`.
- Две шкалы: 1024 (KiB/MiB/…) и 1000 (KB/MB/…); не путать в подписях.
- JS в `views/625/script.php` — зеркало сервиса (алиасы единиц совпадают с PHP).
- Манифест: `config/nj_module.php` (slug `bytes`, группа «Конвертеры»).
