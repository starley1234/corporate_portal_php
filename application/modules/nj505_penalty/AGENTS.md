# nj505_penalty — Калькулятор пеней и неустойки — памятка для агентов

Публичный сервис N2J (группа «Бухгалтерия»): пени по налогам (ст. 75 НК РФ), проценты
за пользование чужими деньгами (ст. 395 ГК РФ), договорная неустойка с потолком и
сравнением с «ориентирами суда» (ст. 395 ГК и двойная ключевая ставка, ст. 333 ГК).

- Страница: `/penalty` — состояние в адресе:
  `?m=tax|gk395|contract&a=100000&f=2026-08-01&t=2026-09-15&p=person&i=0&mor=0&r=0.1&c=10`
- API: `POST|GET /nj505/api/calc` `{mode, amount, due, paid?, payer, incl, moratorium, rate, cap, today?}`
  → `{ok, result:{total_kop, rows[], days, excluded, refs, warnings…}}` (деньги — в копейках);
  ошибки HTTP 400 с `error`: bad_mode, bad_amount, bad_date, bad_rate, too_early, no_delay, too_big, no_rate.
  `GET /nj505/api/rates` — история ключевой ставки
- Таблиц, миграций, воркеров нет. Данные — `config/nj505_penalty.php`
- Зависит от `nj501_vat` (деньги) и `nj508_calendar` (разбор и формат дат)

## Правила для агента

- **Ключевая ставка — таблица в конфиге, и её надо пополнять после КАЖДОГО заседания ЦБ**
  (решение в пятницу, действует с понедельника; календарь заседаний — cbr.ru). Добавить строку
  в КОНЕЦ `key_rate`, сдвинуть `as_of` и `next_meeting`. Если `today > next_meeting` и запись не
  добавлена — страница сама предупреждает пользователя («ставка могла измениться»). Не оставляй
  это предупреждение висеть: обновляй таблицу.
- Счёт по дням: просрочка — со дня после срока платежа по день уплаты ВКЛЮЧИТЕЛЬНО (`incl=0` убирает
  день уплаты). Соседние дни с одинаковыми параметрами сливаются в строки; сумма каждой строки
  округляется до копейки half-up, итог — сумма строк. Целочисленно: ставки в тысячных долях
  процента; `MAX_SUM` (100 млн ₽) защищает от переполнения int.
- 1/150 для организаций — с 31-го календарного дня (`day_no >= 31`); ИП/физлица — всегда 1/300.
- Ст. 395 ГК: делитель 365/366 берётся по КАЖДОМУ дню (год дня), а не по году начала.
  Раньше 01.08.2016 ключевая ставка в 395 не применялась → `too_early`. Пени НК — с 01.01.2016.
- Мораторий ПП № 497 (01.04–01.10.2022) исключает дни только в gk395/contract, на налоговые
  пени не влияет. Мораторий 2020 (ПП № 428) НЕ применяем — он для отдельных отраслей.
- Будущая дата уплаты: считаем по последней известной ставке и предупреждаем.
- Не считаем: пени по ЕНС с учётом сальдо и зачётов, штрафы (ст. 122 НК), проценты по ст. 317.1 ГК,
  уменьшение долга частичными платежами — это отдельный режим, если понадобится.
