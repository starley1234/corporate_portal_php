# Поток заказчиков (nj606_leads)

Назовите, **какие компании вам нужны** (например, «производители металлоконструкций»
и регион) — платформа соберёт подходящих производителей в открытых источниках:
с сайтами, описанием деятельности и зацепкой для первого письма.

- **Потоки** — создание и управление подборками (`/leads`);
- **Лента компаний** — найденные компании с ссылкой на сайт и зацепкой;
- **В один клик** — из компании сразу можно собрать профиль (nj591) или
  подготовить холодное письмо (nj592).

Сбор потока — платный (списание кредита через nj601): бета стоит дёшево,
а первый сбор запускается сразу после создания потока.

## Как это устроено

```
создание потока (кредит nj601) → задача nj120 (nj606.leads) → python-воркер
(открытые источники) → компании в /leads
```

Сервис для зарегистрированных пользователей (лиды привязаны к аккаунту).
Источники — только открытые; баз «всех подряд» нет.

## Формы и перезагрузка (26.09.2026)

Поток создаётся платно (кредит nj601), поэтому повтор отправки формы особенно
дорог: F5 после создания списывал кредит второй раз и создавал копию потока.

* любой POST завершается редиректом на чистый GET (`/leads?flash=…`, 303) либо
  JSON-ответом для AJAX-кнопок («Собрать», отметка лида) — страница не рендерится
  на POST;
* одинаковый «что производит» + регион у того же пользователя — не новый поток:
  включаем существующий и запускаем сбор, **без второго списания кредита**.

## Админка

`/leads/admin` — все потоки и компании, счётчики, удаление (роль admin).
