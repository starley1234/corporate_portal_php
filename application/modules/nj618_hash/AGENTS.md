# Хеш-инструмент (модуль 618) — памятка для агентов

MD5, SHA-1, SHA-256/384/512 для строк — локально (WebCrypto) и через сервер.

**Публичный сервис** для разработчиков и ИИ-агентов. Работает и в браузере
(локально), и через серверный JSON API — серверный прогон используется для
интеграций, агентов и контроля результатов (не позиционируется как чисто
браузерный инструмент).

## Маршруты

- Страница: `/hash`
- API: `POST /nj618/api/hash`

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj618_*` в `classes/Service/Nj618/`.
- Точки HTTP: `/hash` (страница) и `POST /nj618/api/hash` (JSON API).
- JS в `views/618/script.php` — зеркало сервиса; правки логики дублировать в обе стороны.
- Манифест каталога: `config/nj_module.php` (slug, группа, keywords, card_view).
