# Cron-человечизатор (модуль 621) — памятка для агентов

Перевод cron-выражения на человеческий язык + следующие запуски.

**Публичный сервис** для разработчиков и ИИ-агентов. Работает и в браузере
(локально), и через серверный JSON API — серверный прогон используется для
интеграций, агентов и контроля результатов (не позиционируется как чисто
браузерный инструмент).

## Маршруты

- Страница: `/cron`
- API: `POST /nj621/api/explain`

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj621_*` в `classes/Service/Nj621/`.
- Точки HTTP: `/cron` (страница) и `POST /nj621/api/explain` (JSON API).
- JS в `views/621/script.php` — зеркало сервиса; правки логики дублировать в обе стороны.
- Манифест каталога: `config/nj_module.php` (slug, группа, keywords, card_view).
