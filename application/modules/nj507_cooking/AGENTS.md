# nj507_cooking — кулинарный конвертер — памятка агенту

Справочник `/cooking`: стаканы 200/250 мл, столовая/десертная/чайная ложки, щепотка, диапазоны массы 35 продуктов, масштабирование порций и эквивалентная площадь форм. Для длинного хвоста запросов есть `/cooking/<product>`.

## Контракт
- `Service_Nj507_Cooking::calculate(product, measure, amount, direction, from_servings, to_servings)` — расчёт массы/меры и порций.
- `::form_factor(from_shape, from_a, from_b, to_shape, to_a, to_b)` — коэффициент ингредиентов по площади форм.
- Таблицы и источники — только `config/nj507_cooking.php`. Плотность продукта задана интервалом г/мл; нельзя превращать ориентир в одну «точную» цифру.
- API: `POST /nj507/api/convert`, `POST /nj507/api/form`, `GET /nj507/api/products`. Stateless, без истории.
- Индексируемые карточки продуктов объявляются в `config/nj_module.php` (`sitemap`) и рендерятся одним шаблоном.

## Правила
- Меры по умолчанию без «горки»: стакан 200/250 мл, ст. л. 15 мл, дес. л. 10 мл, ч. л. 5 мл. Щепотка помечается как особенно условная.
- Порции ограничены 1–1000; размеры формы — 1–200 см. Не ослаблять пределы API без причины.
- Проверять `tests/Unit/CookingServiceTest.php` и `tests/Js/cooking_parity.mjs`; все страницы продукта должны отвечать 200, неизвестный slug — 404.
- Не подключать внешние API/скрипты и не сохранять ингредиенты пользователя.
