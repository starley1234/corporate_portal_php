# Кулинарные меры (`nj507_cooking`)

`/cooking` и `/cooking/<product>` — справочник массы 35 продуктов в стаканах и ложках, обратный перевод граммов в меру, изменение числа порций и пересчёт площади форм для выпечки.

- Источник истины: `config/nj507_cooking.php` (объём мер, продукты, диапазоны плотности и ссылки на справочники).
- API: `POST /nj507/api/convert`, `POST /nj507/api/form`, `GET /nj507/api/products`.
- Данные готовятся локально; ничего не отправляется во внешние сервисы и не сохраняется.
- Величины намеренно показываются диапазонами: способ набора, влажность и конкретный продукт меняют массу.
