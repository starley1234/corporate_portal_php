> (протокол: docs/CONTEXT.md).

Публичный сервис N2J (группа «Текст»): текст → аудиофайл через OmniVoice API
v1. Страница `/voice` — форма (модель, голос, скорость, формат, язык,
инструкция «как говорить»), плеер, скачивание и история озвучек. Синтез
требует аккаунта: внешний API считает время GPU, гость видит `Gate::wall`.

## Таблицы (полное владение)

- `nj_665_speeches` — журнал озвучек: `code` (он же имя файла в
  storage/nj665), `user_id`, `visitor_uid`, `client_ip`, `model`, `voice`,
  `format`, `speed`, `language`, `instructions`, `chars`, `bytes`, `title`,
  `excerpt`, `status` (`done` | `error`), `error`, `plays`, `downloads`,
  `created_at`, `last_access_at`, `deleted_at` (миграция 002 — мягкое
  удаление). По `client_ip` считает лимитер; `deleted_at IS NULL` — живые
  строки (история и открытие по коду ходят только по ним).
- `nj_665_catalog` — кеш ответов внешнего API: `key` (`models` — каталог
  моделей/голосов/форматов, `key` — состояние ключа), `payload`, `updated_at`.

## Маршруты и API

- `GET|POST /voice` — страница; POST работает без JS (auth: login для синтеза).
- `GET /voice/f/<code>` — файл озвучки (`?dl=1` — вложением); считает `plays`
  или `downloads`.
- `GET /voice/h/<code>` — страница одной озвучки (для ссылки).
- `POST /voice/api/synthesize` — синтез (auth: login + csrf).
- `GET /voice/api/voices` — модели, голоса, форматы, умолчания, лимиты;
  `?model=<id>` — для конкретной модели, `?refresh=1` — минуя кеш.
- `GET /voice/api/history` — последние озвучки посетителя.
- `POST /voice/api/delete` — удалить свою озвучку (`code` + `csrf`): строку
  помечает `deleted_at`, аудиофайл стирает с диска. Чужой код не пройдёт —
  проверяет `Service_Nj665_Voice::owns()` (свой по `user_id` либо по
  `visitor_uid`).
- `GET /voice/api/key` — состояние ключа внешнего API (auth: admin).

## Правила, которые нельзя нарушать

1. **Только эндпоинты v1.** Синтез — `POST /api/v1/audio/speech`, каталог —
   `GET /api/v1/models?output_modalities=speech`, ключ — `GET /api/v1/key`.
   Старые `/tts/v1/synthesize` и `/voices` не трогать: владелец просил v1
   (09.10.2026), а они не знают ни моделей, ни инструкций голосу.
2. **Формат ответа синтеза не зафиксирован** — это главный риск. Разбор
   всегда через `Service_Nj665_Voice::audio_from_response()`: JSON с base64 →
   JSON со ссылкой → сырой поток. Добавляя новую ветку, добавляй проверку в
   стенд и в `tests/Unit/Nj665VoiceTest.php`.
3. **Формат файла берётся по содержимому, а не из запроса.** `sniff_format()`
   важнее объявленного `response_format`: mp3, пришедший на запрос pcm, обязан
   сохраниться как `.mp3` и отдаться с `audio/mpeg`, иначе браузер его не
   проиграет.
4. **pcm по умолчанию не используем.** В спеке `response_format` по умолчанию
   `pcm` — сырой поток без контейнера. Конфиг просит `mp3`, а `pick_format()`
   не даст выбрать формат, которого модель не объявила.
5. **Ключ — только из `.env`.** Никаких ключей в конфиге, вьюхах и логах;
   `GET /voice/api/key` доступен администратору, на странице блок с ключом —
   под `can('nj665.admin')`.
6. **Код озвучки проверяется шаблоном** (`[23456789a-z]{8,24}`) и в маршруте,
   и в `speech()`: путь до файла собирается из `code` + расширения из журнала,
   пользовательские строки в имени файла не участвуют.
7. **Синтез — только по аккаунту** и под лимитером (`per_minute`/`per_hour`
   по `client_ip`). Снимать замок нельзя: внешний API платный.
8. **Ссылку из ответа качаем только по http(s)** и коротким таймаутом
   (`fetch_url`): это ответ чужого сервера, а не наш файл.
9. **Удаление двухслойное и необратимое.** Строка только помечается
   (`deleted_at`), файл стирается с диска сразу — восстановить озвучку без
   внешнего API нельзя, поэтому браузер спрашивает подтверждение до запроса.
   Порядок такой: сначала UPDATE (если он не пройдёт, файл останется цел и
   озвучка продолжит играть), потом `unlink`. Помеченные строки sweep()
   убирает через сутки, живые — через `ttl_days`.

## Не трогать / подводные камни

- Формат в v1 может не совпасть с запрошенным — см. правило 3.
- Каталог моделей кешируется в `nj_665_catalog` на `catalog_ttl` минут; при
   недоступности API `models()` отдаёт последний кеш и НЕ падает. Не
   заменяй это на исключение: страница обязана открываться без внешнего API.
- `response_format` — имя поля именно такое (не `format`): в v1 внутри
  `SpeechRequest` это отдельный ключ.
- Форма работает и без JS: не уноси валидацию только в браузер.
