# Markdown-вьюер (модуль 615) — памятка для агентов

Конвертация Markdown в безопасный HTML (заголовки, списки, код, таблицы, ссылки).

**Публичный сервис** для разработчиков и ИИ-агентов. Работает и в браузере
(локально), и через серверный JSON API — серверный прогон используется для
интеграций, агентов и контроля результатов (не позиционируется как чисто
браузерный инструмент).

## Маршруты

- Страница: `/markdown`
- API: `POST /nj615/api/render`

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj615_*` в `classes/Service/Nj615/`.
- Точки HTTP: `/markdown` (страница) и `POST /nj615/api/render` (JSON API).
- JS в `views/615/script.php` — зеркало сервиса; правки логики дублировать в обе стороны.
- Манифест каталога: `config/nj_module.php` (slug, группа, keywords, card_view).
