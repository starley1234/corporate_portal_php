# Модуль Prx212_Storage

Модуль `Prx212_Storage` предоставляет функциональность для работы с файловым хранилищем в системе Prx212. Он включает в себя API для загрузки, получения метаданных и удаления файлов, а также контроллер для скачивания файлов с проверкой прав доступа. Модуль поддерживает различные бэкенды хранения, такие как локальная файловая система и Amazon S3.

## Структура модуля

Модуль состоит из следующих основных компонентов:

-   **`Controller_Prx212_Api`**: REST API для взаимодействия с файловым хранилищем.
-   **`Controller_Prx212_Download`**: Контроллер для безопасного скачивания файлов.
-   **`Service_Prx212_Storage`**: Основной сервис, инкапсулирующий логику работы с файлами и бэкендами хранения.

## `Controller_Prx212_Api`

Этот контроллер предоставляет RESTful API для управления файлами. Все ответы возвращаются в формате JSON.

### Методы API

#### 1. Загрузка файла

-   **URL**: `/prx212_api/upload`
-   **Метод**: `POST`
-   **Тип контента**: `multipart/form-data`

**Параметры запроса**:

-   `file` (обязательно): Загружаемый файл (передается через `$_FILES`).
-   `is_public` (опционально): `0` или `1`. Если `1`, файл будет публичным. По умолчанию `0`.
-   `backend_id` (опционально): ID бэкенда хранения, если нужно использовать конкретный.

**Пример успешного ответа**:

```json
{
    "success": true,
    "message": "Файл успешно загружен.",
    "data": {
        "id": 123,
        "backend_id": 1,
        "user_id": 456,
        "filename": "my_document.pdf",
        "storage_path": "local/1/2023-10-27/abcdef12345.pdf",
        "mime_type": "application/pdf",
        "file_size": 102400,
        "extension": "pdf",
        "hash": "...",
        "is_public": 0,
        "created_at": "2023-10-27 10:00:00",
        "updated_at": "2023-10-27 10:00:00",
        "deleted_at": null
    },
    "timestamp": 1678886400
}
```

**Пример ответа с ошибкой**:

```json
{
    "success": false,
    "error": "Файл обязателен для загрузки.",
    "code": 400,
    "timestamp": 1678886400
}
```

#### 2. Получение метаданных файла

-   **URL**: `/prx212_api/get_metadata/<id>`
-   **Метод**: `GET`

**Параметры URL**:

-   `id` (обязательно): ID файла.

**Пример успешного ответа**:

```json
{
    "success": true,
    "message": "Успешно",
    "data": {
        "id": 123,
        "backend_id": 1,
        "user_id": 456,
        "filename": "my_document.pdf",
        "storage_path": "local/1/2023-10-27/abcdef12345.pdf",
        "mime_type": "application/pdf",
        "file_size": 102400,
        "extension": "pdf",
        "hash": "...",
        "is_public": 0,
        "created_at": "2023-10-27 10:00:00",
        "updated_at": "2023-10-27 10:00:00",
        "deleted_at": null
    },
    "timestamp": 1678886400
}
```

**Пример ответа с ошибкой**:

```json
{
    "success": false,
    "error": "Файл не найден.",
    "code": 404,
    "timestamp": 1678886400
}
```

#### 3. Удаление файла (мягкое удаление)

-   **URL**: `/prx212_api/delete/<id>`
-   **Метод**: `DELETE`

**Параметры URL**:

-   `id` (обязательно): ID файла.

**Пример успешного ответа**:

```json
{
    "success": true,
    "message": "Файл успешно удален.",
    "data": {
        "id": 123
    },
    "timestamp": 1678886400
}
```

**Пример ответа с ошибкой**:

```json
{
    "success": false,
    "error": "Доступ запрещен. Недостаточно прав для удаления файла.",
    "code": 403,
    "timestamp": 1678886400
}
```

## `Controller_Prx212_Download`

Этот контроллер обрабатывает запросы на скачивание файлов, обеспечивая проверку прав доступа и потоковую передачу данных.

### Методы

#### 1. Скачивание файла по ID

-   **URL**: `/prx212_download/file/<id>`
-   **Метод**: `GET`

**Параметры URL**:

-   `id` (обязательно): ID файла.

Этот метод проверяет права пользователя на скачивание файла через ACL (`prx212_storage.download_file`). Если доступ разрешен, файл передается клиенту.

#### 2. Скачивание файла по временному токену

-   **URL**: `/prx212_download/shared/<token>`
-   **Метод**: `GET`

**Параметры URL**:

-   `token` (обязательно): Временный токен, сгенерированный методом `Service_Prx212_Storage::generateUrl()`.

Этот метод позволяет скачивать файлы по предварительно сгенерированным временным ссылкам. Токен проверяется на валидность и срок действия.

### Обработка ошибок

В случае ошибок (например, файл не найден, доступ запрещен, недействительный токен) контроллер возвращает соответствующий HTTP-статус и JSON-ответ с описанием ошибки.

**Пример ответа с ошибкой**:

```json
{
    "error": "Файл не найден или доступ запрещен"
}
```

## `Service_Prx212_Storage`

Сервис `Service_Prx212_Storage` является центральным компонентом модуля, предоставляющим API для работы с файлами и абстрагирующим логику хранения от конкретных бэкендов.

### Основные методы

-   **`instance()`**: Возвращает синглтон-экземпляр сервиса.
-   **`getFilePath($file_id)`**: Возвращает полный путь к файлу для локального драйвера.
-   **`getFileForDownload($file_id, $user_id = null)`**: Подготавливает данные файла для скачивания, включая проверку прав доступа.
-   **`getFileByToken($token)`**: Подготавливает данные файла для скачивания по временному токену.
-   **`get_files_list(array $params = [])`**: Получает список файлов с фильтрацией и пагинацией.
-   **`get_storage_stats(array $params = [])`**: Получает статистику хранилища (общее количество файлов, общий размер).
-   **`get_active_backends()`**: Возвращает список активных бэкендов.
-   **`get_all_backends()`**: Возвращает список всех бэкендов (включая неактивные).
-   **`set_driver($driver_name)`**: Устанавливает активный бэкенд по имени драйвера.
-   **`saveRaw($content, $filename, array $metadata = [])`**: Сохраняет файл из сырых данных (строки).
-   **`save($file, array $metadata = [])`**: Сохраняет файл из загруженного файла или по пути.
    -   `$file`: Массив `$_FILES['file']` или путь к файлу.
    -   `$metadata`: Массив с дополнительными метаданными (`is_public`, `backend_id`, `user_id`, `custom_path`).
-   **`delete($file_id)`**: Мягкое удаление файла (устанавливает `deleted_at`).
-   **`generateUrl($file_id, $expires_seconds = 3600)`**: Генерирует временный URL для скачивания файла. Для S3 генерирует предподписанный URL, для локального хранилища - URL с временным токеном.
-   **`get_access_logs(array $params = [])`**: Получает логи доступа (на основе таблицы `prx_212_links`).
-   **`validate_mime($mime_type)`**: Проверяет, разрешен ли данный MIME-тип для загрузки.
-   **`get_max_size()`**: Возвращает максимально разрешенный размер файла для загрузки.

### Поддерживаемые бэкенды хранения

Модуль поддерживает следующие драйверы хранения:

-   **`local`**: Локальная файловая система. Файлы хранятся в директории, указанной в конфигурации.
-   **`s3`**: Amazon S3 (или совместимые хранилища). Требует установленного AWS SDK.

### Конфигурация

Конфигурация модуля — `application/modules/prx212_file_storage/config/prx212_storage.php`.
Локальный default находится в корневом `storage/prx212_file_storage/files`,
а не в `public_html`. Корень и подкаталоги создаются при первом сохранении;
`bin/setup.sh` также готовит их заранее. Стандартные права: каталоги `0700`,
новые файлы `0600` (backend может явно задать `chmod`). Физическую выдачу
заменяет контроллер `/storage/get/<id>` с проверкой прав.

Пример конфигурации:

```php
<?php defined('SYSPATH') or die('No direct script access.');

return array(
    'allowed_mime_types' => array(
        'image/jpeg',
        'image/png',
        'application/pdf',
        'application/msword',
        'application/vnd.openxmlformats-officedocument.wordprocessingml.document',
        // ... другие разрешенные MIME-типы
    ),
    'upload_max_size' => 10485760, // 10 MB
    'local_storage_paths' => array(
        'default' => dirname(APPPATH) . '/storage/prx212_file_storage/files',
    ),
    // ... другие настройки
);
```

Бэкенды настраиваются через БД (`prx_212_storage_backends`): для `local`
явный JSON `config_data.root_path` имеет приоритет над default. Произвольный
относительный путь по-прежнему считается от рабочего каталога процесса, который
может различаться для CLI и FPM; используйте согласованный абсолютный путь.
Старый проектный `public_html/storage/*` разрешается в `storage/*`; содержимое
нужно сначала перенести вручную по
[процедуре](../../../docs/ENVIRONMENT.md#перенос-существующего-public_htmlstorage).
Остальные внешние пути не переключаются автоматически. Настроенные пути в
другие части проектного `public_html` и symlink на них отклоняются: перед
обновлением их нужно отдельно скопировать и изменить конфигурацию.

В новых вызовах `save()` поле `module` — буквы/цифры, `_` и `-`, от 1 до 50
символов, первая — буква или цифра. В пути файла внутри backend запрещены
компоненты `.`/`..` и symlink; существующие нестандартные записи следует
проверить до перехода. Сохранение не перезаписывает существующий файл.

### События

Публикует `Event::publish('prx212.file.<action>', [...], $initiator_id)` — payload
только ID и скаляры, ORM-объекты в события не передаются:

-   `prx212.file.uploaded`: файл сохранён (`file_id`, `filename`, `mime_type`, `size`, `hash`, `module`, `is_public`, `user_id`).
-   `prx212.file.deleted`: файл удалён (`file_id`, `filename`, `mime_type`, `size`, `module`).
-   `prx212.file.downloaded`: скачивание по ID (`file_id`, `user_id`).
-   `prx212.file.shared_downloaded`: скачивание по временному токену (`file_id`; сам токен в журнал не попадает).

### Права доступа (ACL)

Модуль использует систему ACL для проверки прав доступа к файлам:

-   `prx212_storage.upload`: Разрешение на загрузку файлов.
-   `prx212_storage.read`: Разрешение на чтение метаданных файла.
-   `prx212_storage.delete`: Разрешение на удаление файла.
-   `prx212_storage.download_file`: Разрешение на скачивание файла по ID.
-   `prx212_storage.download_shared_file`: Разрешение на скачивание файла по временному токену.

Проверки прав выполняются в контроллерах и сервисе.
