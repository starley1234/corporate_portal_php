# NJ-674 MCP Guard

`/mcpguard` принимает MCP `tools/list` JSON и делает ограниченный статический
разбор названий, схем `inputSchema` и аннотаций (`readOnlyHint`, `destructiveHint`,
`openWorldHint`). Внешних запросов нет, исходный JSON не сохраняется и в отчёт
попадают только имена инструментов и коды/описания правил.

Это beta-инспектор метаданных, не динамический red-team и не сертификация сервера:
он не видит реализацию, авторизацию, поведение tools/call и реальные ACL.
Администратор должен вручную сверить находки с исходным MCP-сервером. Следующий
этап — динамический запуск только на встроенном sandbox или явно allowlisted
сервере после подтверждения права тестировать его; текущая версия сетевых запросов
не выполняет.

Проверка: `N2J_ROOT=$PWD node .tools/phpwasm_stand.mjs .tools/nj674_mcpguard_stand.php`.
