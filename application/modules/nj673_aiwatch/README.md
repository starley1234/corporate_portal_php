# NJ-673 AI Watch

`/aiwatch` показывает динамику аудитов `/aiscan`: для одной пары endpoint+model
сравнивает два последних завершённых полных отчёта, выводит разницу security score,
числа провалов и новые строки OWASP со статусом fail/critical.

Это слой наблюдения, не второй сканер: AI Watch читает `Service_Nj672_Scan::history()`
и не пересчитывает вердикт. Секреты и копии отчётов не сохраняет. Для сравнения
нужны два завершённых полных аудита одной цели; разные наборы проверок могут менять
результат, поэтому сравнение — сигнал для оператора, не автоматический release gate.

Доступ только администраторам. Следующий этап: расписание контрольных прогонов,
базовые профили по окружениям и уведомление о подтверждённой регрессии.
