# Сторож контрагентов (nj609_watchdog)

Добавьте клиентов и поставщиков в наблюдение — платформа будет раз в неделю
проверять их и присылать **только реальные сигналы риска**: суды, банкротства,
смены в ЕГРЮЛ, заметные негативные новости. Без шума.

- **Мои контрагенты** — список наблюдений (название, ИНН, заметка);
- **Лента событий** — сигналы с типом и ссылкой на источник;
- **Фильтр шума** — приходят именно значимые события, а не «всё подряд»;
- **Бесплатно** — в бете проверка не списывает кредит.

## Как это устроено

```
добавить контрагента → раз в ~7 дней задача nj120 (nj609.watchdog) →
python-воркер (открытые источники) → сигналы риска в /watchdog
```

Для зарегистрированных пользователей (наблюдения привязаны к аккаунту).

## Админка

`/watchdog/admin` — все субъекты и события (роль admin).
