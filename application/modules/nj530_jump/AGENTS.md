# nj530_jump — Сокращатель ссылок (Need 2 Jump) — памятка для агентов

- Форма: `/jump`, короткая ссылка `/x/<code>`, статистика `/jump?c=<code>`
- Дедупликация URL, счётчик переходов, 302-редирект
- API: `POST /nj530/api/shorten`, `GET /nj530/api/stats/<code>`
- Таблица: `nj_530_links`
- **06.10.2026:** создание ссылок (веб-форма и API shorten) — только для
  зарегистрированных (решение владельца): анонимный сокращатель на домене
  n2j.ru — готовый спам-инструмент, ссылки «живут вечно». Гость видит плашку
  входа, POST → `/auth/login`, API отвечает 401 + `login`. Переходы `/x/<code>`
  и статистика — публичные, как и раньше.

## Правила для агента

nj-сервис с БД. Хранит ссылки и счётчик переходов.

## Контракт
- Сервис: `Service_Nj530_Jump` — единственная точка работы с `nj_530_links` (стиль NJ-120: `Database::instance()` + `quote()`).
- Таблица: `nj_530_links` (code UNIQUE, url, host, user_id NULL, clicks BIGINT).
- Дедупликация: одинаковый URL → тот же код (SELECT по url перед вставкой).
- Страницы: `/jump` (форма+статистика `?c=код`), `/x/<code>` — редирект 302 + `clicks+1` (только GET).
- API: `POST /nj530/api/shorten`, `GET /nj530/api/stats/<code>`. CSRF: формы — `Security::token()`.

## Приватность (железное правило)
- Храним только счётчик переходов. **IP, user-agent, рефререры — не сохранять никогда.**

## Не делать
- Не менять коды существующих ссылок (внешние ссылки умрут).
- Редирект только 302 (не 301 — код должен остаться правляемым).
- Не редактировать `modules/`, `system/`; миграции после применения не менять — только 002+.

## Админка (/nj530/admin, роль admin)

Список ссылок с поиском (код/URL/хост/IP создателя), журнал последних
переходов (IP), удаление ссылок (POST+CSRF). QR-код на /jump — локальная
библиотека `public_html/assets/vendor/qrcode/qrcode.js` (qrcode-generator,
MIT), инициализация в views/530/script.php по #nj530-qr.
