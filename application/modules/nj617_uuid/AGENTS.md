# Генератор идентификаторов (модуль 617) — памятка для агентов

UUID v4, UUID v7 (RFC 9562) и ULID — пачками до 100 штук.

**Публичный сервис** для разработчиков и ИИ-агентов. Работает и в браузере
(локально), и через серверный JSON API — серверный прогон используется для
интеграций, агентов и контроля результатов (не позиционируется как чисто
браузерный инструмент).

## Маршруты

- Страница: `/uuid`
- API: `GET /nj617/api/generate`

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj617_*` в `classes/Service/Nj617/`.
- Точки HTTP: `/uuid` (страница) и `GET /nj617/api/generate` (JSON API).
- JS в `views/617/script.php` — зеркало сервиса; правки логики дублировать в обе стороны.
- Манифест каталога: `config/nj_module.php` (slug, группа, keywords, card_view).
