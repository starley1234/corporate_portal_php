# nj659_yandexauth — вход через Яндекс

OAuth 2.0 (authorization code, server-side): кнопка «Войти через Яндекс» на
странице входа, привязка Яндекса к существующему аккаунту, автосоздание
аккаунтов, диагностика связок для админа.

- **Настройка:** `.env` — `YANDEX_OAUTH_CLIENT_ID`, `YANDEX_OAUTH_CLIENT_SECRET`,
  `YANDEX_OAUTH_REDIRECT_URI` (redirect в кабинете Яндекса:
  `https://<домен>/auth/yandex/callback`). Без настроенных ключей сайт
  работает как раньше — кнопка просто не показывается.
- **Вход:** гостю достаточно кнопки; при первом входе аккаунт создаётся с
  email из профиля Яндекса (отключается `autocreate` в конфиге модуля).
- **Привязка:** залогиненный пользователь, открыв `/auth/yandex`, связывает
  Яндекс со своим аккаунтом; отвязка — POST `/auth/yandex/unlink`.
- **Админу:** `/nj659/admin` (право `nj659.yandexauth`) — список связок,
  последний вход, отвязка.

Подробности — в [AGENTS.md](AGENTS.md).
