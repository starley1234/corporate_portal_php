# nj664_jsondecode — Декодер JSON

- Страница: `/json-decode` — вход слева, разбор справа, разбор живой
- Понимает: честный JSON, экранированный `{\"a\":1}`, URL-кодированный
  `%7B%22a%22%3A1%7D`, HTML-сущности `&quot;`, JSON в кавычках
- Вывод: красивый JSON, сжатый в одну строку, вид глазами `print_r`, готовый
  PHP-код `json_decode()`
- Ошибка — с указанием строки и позиции
- Загрузка: файлом, по адресу URL, из буфера; ссылка с данными `?input=…`
- API: `POST /nj664/api/decode` (`mode`: `json|min|array|php|all`),
  `GET/POST /nj664/api/sample`
- Таблиц и очередей нет: JSON не сохраняется

Инструкции для агента — см. `AGENTS.md` рядом.
