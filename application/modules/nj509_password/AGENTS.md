# nj509_password — Генератор паролей — памятка для агентов

Публичный сервис N2J: криптостойкие пароли до 96 символов.

- Страница: `/password` (новый пароль на каждую загрузку)
- API: `POST /nj509/api/generate` (JSON, публичный, `no-store`)
- Таблиц/воркеров нет; алгоритм — `Service_Nj509_Password` (random_int, CSPRNG)
- Пароли нигде не сохраняются: ни БД, ни логи, ни localStorage

## Правила для агента

Третий публичный сервис N2J (аудитория — разработчики и все, кому нужны пароли). Stateless: **без БД, без воркеров.**

## Контракт
- Класс-истина: `Service_Nj509_Password` (наборы, исключение похожих, random_int, Фишер—Йетс, энтропия).
- Страница: `Controller_Nj509_Password` → `/password`; SSR генерирует стартовый пароль на каждый GET.
- API: `Controller_Nj509_Api` → `POST /nj509/api/generate` `{length, upper, lower, digits, symbols, exclude_ambiguous, count≤20}`; ответ `Cache-Control: no-store`.
- JS-зеркало: `views/509/script.php` (инлайн) — `crypto.getRandomValues` **с отбраковкой** (без modulo bias).

## Железные правила
- **Пароли не сохраняются нигде**: ни БД, ни логи, ни localStorage. Не добавлять «историю паролей» никогда.
- Минимум по одному символу из каждого включённого набора (иначе тумблеры врут).
- При изменении наборов/алгоритма — менять PHP и JS вместе, тесты `tests/Unit/PasswordServiceTest.php`.

## Не делать
- Таблицы/воркеры не добавлять.
- Не редактировать `modules/`, `system/`; статику внутрь модуля не класть (инлайн — исключение).
