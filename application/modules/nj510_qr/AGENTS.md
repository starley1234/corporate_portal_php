# nj510_qr — генератор QR-кодов

## Состояние работ
- **02.10.2026:** `/qr` поддерживает семь типов данных, одиночный/пакетный режим
  до 200 кодов, стили, логотип, PNG/SVG/JPEG, ZIP, генерацию ID по маске и
  печать пакета на листах A4 (3 × 4, до 12 QR на лист).
- С логотипом центральные модули QR удаляются из SVG-матрицы, а не просто
  перекрываются плашкой. После рендера браузер повторно декодирует итоговый
  raster через jsQR; ошибка блокирует экспорт/печать по умолчанию.
- Маска: `#` — цифра, `*` — A–Z/0–9, остальные разрешённые знаки — литералы;
  `\#`, `\*`, `\\` задают литеральные специальные знаки. Случайная часть
  берётся через Web Crypto с rejection sampling, повторы в пакете исключаются.
- Stateless: БД, очередей, env и API нет. Содержимое, логотипы и ID не уходят
  в HTTP и не сохраняются; в localStorage допускаются только настройки стиля.
- `npm run test:qr` — 25 тестов, включая независимое декодирование QR с
  резервированной зоной логотипа. Chromium smoke `.tools/nj510_qr_ui_smoke.mjs`
  прошёл 11 сценариев: ID маски генерируются уникально, 13 QR читаются и
  раскладываются в A4 (12 + 1); проверены логотип, PNG/SVG/JPEG, ZIP, отмена,
  мобильная вёрстка и отсутствие сетевой отправки.

## Контракт
- `Controller_Nj510_Qr` — тонкий контроллер `/qr`. Query только `mode=batch` и
  разрешённый `type` (`wifi`, `vcard`, …). Не принимать данные/пароль в URL.
- `Service_Nj510_Qr::settings()` — единственный источник типов, лимитов,
  размеров и пресетов. `initial_state()` проверяет переключатели страницы.
- `views/510/index.php` — форма без отправки, предпросмотр, FAQ/JSON-LD;
  `script.php` подключает **локальные** библиотеки и JS с `defer` в порядке.
- `views/nj510/card.php`, манифест — главная/каталог, группа «Ссылки», `pin=TRUE`.
  `/s/tools` включает `qr`; адрес добавлен в sitemap модуля nj602. Новость —
  идемпотентной миграцией `nj604_news/008_Qr_News`.
- `public_html/assets/js/nj510-qr-core.js` — чистые функции payload, CSV,
  масок ID, безопасных имён, стиля, матрицы и SVG. `nj510-qr.js` — DOM, файлы,
  ZIP, печать A4, проверка читаемости, clipboard и сохранение **только стиля**.

## Инварианты
- QR строится существующим qrcode-generator (MIT) из локального assets.
  UTF-8-конвертер временный: после кодирования вернуть прежний, иначе ломаем 2FA.
- Служебные модули (тайминг/выравнивание/версия) квадратные; скруглять можно
  данные и три угловые метки. Не убирать светлое поле (минимум 4 модуля).
- Логотип только из локального PNG/JPEG/WebP: проверить сигнатуру, размер и
  геометрию, нормализовать canvas в PNG. SVG/URL логотипа не принимать.
  Ширина 12–20%, защита **H** принудительная. Перед SVG формируется
  `visibleMatrix` с целиком очищенными модулями в зоне логотипа; не заменять
  эту очистку одним белым прямоугольником. При плохом чтении уменьшить логотип.
- Строгие HEX-цвета, белый список опций, тёмный код на светлом фоне; контраст
  минимум 3:1 (предупреждение до 4,5:1). SVG не содержит пользовательский текст.
- jsQR читает растровую версию итогового SVG/лого и сравнивает текст, не только
  внутреннюю матрицу. Для одиночного кода ошибка чтения блокирует скачивание.
  В пакетном ZIP/печати проверка каждого кода включена по умолчанию; ошибка
  одной строки отменяет экспорт всего пакета.
- Маска ID длиной до `id_mask_chars` (сейчас 64). Литералы — буквы/цифры, `_`,
  `-`, `.`; `#` генерирует цифру, `*` — заглавный ASCII-буквенно-цифровой знак;
  для литеральных `#`, `*`, `\` применять соответствующий escape. Проверять
  ёмкость и уникальность внутри пакета. Случайность — только Web Crypto и без
  смещения через rejection sampling; при недоступном HTTPS/crypto отказать.
- TXT — буквальный построчный ввод; CSV/TSV — явный режим (1–2 колонки).
  Не резать URL по запятой в обычном списке. Пустые/битые CSV не пропускать тихо.
- A4: книжная ориентация, CSS-grid 3 × 4, до 12 кодов на страницу. До открытия
  печати сформировать все картинки, проверить читаемость и загрузку изображений;
  отмена/ошибка не должна оставить частичный документ.
- Имена файлов с уникальным префиксом, без путей/служебных символов.
  В manifest.csv нейтрализовать `= + - @` в начале, чтобы не исполнять формулы.
- Пакет последовательно освобождает canvas, отдаёт управление между кодами,
  ограничен 64 МБ. Отмена не скачивает частичный ZIP. Зафиксировать настройки
  на время генерации, отключить редактирование, вернуть кнопки после ошибки.
- localStorage `nj510.qr.style.v1` содержит только ключи defaults — ни данных,
  ни логотипа. Плохое/закрытое хранилище не мешает работе. Истории кодов нет.

## Проверки
```bash
npm ci
npm run test:qr                       # 25 тестов, независимый jsQR
php .tools/nj510_stand.php            # контроллер/маршрут/вьюха без БД
bin/test --filter QrService           # PHPUnit-контракт
php tests/mini_runner.php QrServiceTest # без Composer
npx playwright install --with-deps chromium
npm run test:qr:ui                    # декодирование, ID, A4, ZIP в браузере
bash .tools/php_check_all.sh application/modules/nj510_qr
npm run build:css
bin/console module:list --markdown=1 --write=1
python3 .tools/context_pack.py index docs/ARCHITECTURE.md --write
```
- CI запускает PHP-стенд и оба JS-стенда; `bin/check-fresh.sh` проверяет `/qr`.
- Без PHP CLI: `npm i --no-save --package-lock=false @php-wasm/node@3.1.54
  @php-wasm/universal@3.1.54` — JS-стенды используют PHP 8.3-in-WASM для рендера.
- Нет загрузки Chromium в песочнице: пакет `@sparticuz/chromium@141.0.0` из
  npm (не коммитить), распаковать `bin/al2023.tar.br` в `/tmp/al2023`, задать
  `LD_LIBRARY_PATH=/tmp/al2023/lib`, `QR_CHROMIUM_EXECUTABLE=/tmp/chromium`.
  Обычный CI использует Chromium Playwright. Описание для тестов, не для прода.
- Предпросмотр без БД: `node .tools/qr_preview.mjs` (0.0.0.0:4173).
  Это настоящая вьюха модуля в изолированной обёртке, не полноценный сайт.

## Зависимости и сборка
- `fflate 0.8.3` (MIT, ZIP), `jsQR 1.4.0` (Apache-2.0, декодер) закреплены
  в devDependencies. Артефакты и лицензии в `public_html/assets/vendor/`.
- После обновления библиотек: `npm run build:qr-vendor`, затем оба теста.
  Сторонние файлы руками не редактировать; Node на проде не нужен.
- Новые Tailwind-классы писать целиком, пересобирать и коммитить app.css.
  При изменении JS обновить суффикс версии в `views/510/script.php`.
- Не добавлять CDN, внешние картинки, аналитику, серверную загрузку файлов
  или связь с чужими таблицами. Для интеграции — сервис/манифест, не чужая view.
