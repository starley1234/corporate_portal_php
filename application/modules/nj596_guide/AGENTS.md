## Правила
* Пользовательский контур — БЕЗ env/таблиц/классов (это для /guide/dev).
* Презентации — config/nj596_presentations.php, ключ = slug манифеста nj110.
* Реестровый манифест может не содержать витринных `group`, `short`, `href` и `api`.
* /guide/dev — только admin; markdown рендерит vendor/Parsedown.php.
* Mermaid — ТОЛЬКО локальный vendor (/assets/vendor/mermaid), CDN запрещён;
  в script.php должен быть fallback (без mermaid — читаемый код).
* Mermaid-метки — в двойных кавычках (кириллица/скобки безопасны).
* Markdown модулей вставляется как HTML Parsedown-ом — XSS не страшен:
  файлы в репо, пишут свои.
* Вёрстка по эталону: крошки+h1, 2/3+1/3, ничего мельче text-xs.

Сервис `solid3d` (nj669): добавлена подробная инструкция для отдельной OpenSCAD-детали, VLM-ракурсов, GLB/STL, версий и модерации.
