# nj596_guide — «Путеводитель»

Автособираемая документация платформы. Два контура:

* **Для пользователей** — `/guide` (обзор по разделам) и `/guide/<slug>`
  (презентация сервиса): человеческие описания, шаги, советы и Mermaid-схемы.
  Источники: манифесты nj110 (`config/nj_module.php` каждого модуля) +
  курируемые презентации `config/nj596_presentations.php` (ключ — slug).
  Без данных для разработчика (env/таблицы — только в dev-контуре).
* **Для разработчиков** — `/guide/dev` (роль admin): по каждому модулю
  Kohana::modules() — манифест, API, MCP-инструменты, отрендеренные
  README.md и AGENTS.md (Parsedown из vendor модуля).

## Адреса

`/guide`, `/guide/<slug>`, `/guide/dev` (admin). Манифест: группа «Справка»,
открыт гостям. Слуги с дефисами (`summa-propisyu`, `date-words`, `pdf-sign`)
поддерживаются, `/guide/dev` зарезервирован перед общим маршрутом.

## Библиотеки

* `public_html/assets/vendor/mermaid/mermaid.min.js` — Mermaid 10.9.3 (npm),
  локально, без CDN; при недоступности схемы остаются читаемым кодом.
* `application/modules/nj596_guide/vendor/Parsedown.php` — 1.7.4 (GitHub).

## Как добавить презентацию сервиса

Добавить секцию с ключом-slug в `config/nj596_presentations.php`
(title, tagline, about, steps[], tips[], mermaid) — карточка на /guide
сразу получит бейдж «инструкция», а `/guide/<slug>` — шаги и схему.

## Актуальность и проверка

Состав карточек и ссылки берутся из текущих манифестов. Инструкция не создаёт
страницу отсутствующего в каталоге сервиса. Подробных инструкций — 28; среди
них Graph3D, 3D-детали, плоские иллюстрации, диалог двух ИИ, озвучивание текста и книг,
декодер JSON, иконки сайта, фотографии чеков, еды и растений, счётчики и QR-коды.
Тренды GitHub описывают чтение опубликованных обзоров и сборку администратором,
а дизайн страницы — подготовку вариантов оформления, не правила платформы.

`Manifest::get()` отдаёт исходный манифест, а не нормализованную карточку
каталога: у платформенного модуля могут отсутствовать `group` и `short`.
Dev-вьюха использует безопасные значения по умолчанию. Содержимое README/AGENTS
читается при запросе; отсутствующий файл не мешает показу остальных модулей.

Регрессионный стенд рендерит dev-документацию и все карточки сервисов,
проверяет настоящие маршруты, экранирование и доступ только администратора:

```sh
N2J_STAND_FILES="$(git ls-files 'application/modules/*/README.md' 'application/modules/*/AGENTS.md' | paste -sd:)" \
  N2J_ROOT="$PWD" node /tmp/phpwasm/phpwasm_stand.mjs .tools/nj596_guide_stand.php
```

Подготовка PHP-in-WASM — в `.tools/phpwasm_stand.mjs`. После правки вьюх —
`npm run build:css`; синтаксис и контракты — `bash .tools/php_check_all.sh application`.
