# AGENTS.md — erp118_links (Мои ссылки)

> Памятка агенту. Общие правила платформы — в корневом /AGENTS.md.

## Назначение
Персональные закладки пользователя: карточки ссылок, добавление в основное
меню, автоопределение иконок, API для виджетов.

## Состояние
- Готовность: рабочий.

## Ключевые классы
| Класс | Роль |
|---|---|
| `Controller_Erp118_Links` | страницы управления ссылками |
| `Controller_Erp118_Widget` | HMVC-виджеты (карточки ссылок) |
| `Model_Erp118_Links` | ORM-модель ссылок |

## Таблицы
- `erp_118_*` (см. migrations_pg) — владелец: этот модуль.

## Маршруты и API
- Страницы и виджеты: `/erp118/...` (см. init.php).
- Виджет в чужих вьюхах: `echo Request::factory('erp118/widget/...')->execute();`

## Не трогать / подводные камни
- Меню пользователя формируется из ссылок «пункт меню» — осторожно с полем
  in_menu/сортировкой при правках схемы.
