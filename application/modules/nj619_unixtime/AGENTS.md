# Unix-время (модуль 619) — памятка для агентов

Конвертер Unix timestamp (секунды/миллисекунды) в дату: ISO, UTC, часовые пояса.

**Публичный сервис** для разработчиков и ИИ-агентов. Работает и в браузере
(локально), и через серверный JSON API — серверный прогон используется для
интеграций, агентов и контроля результатов (не позиционируется как чисто
браузерный инструмент).

## Маршруты

- Страница: `/unixtime`
- API: `GET/POST /nj619/api/convert`

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj619_*` в `classes/Service/Nj619/`.
- Точки HTTP: `/unixtime` (страница) и `GET/POST /nj619/api/convert` (JSON API).
- JS в `views/619/script.php` — зеркало сервиса; правки логики дублировать в обе стороны.
- Манифест каталога: `config/nj_module.php` (slug, группа, keywords, card_view).
