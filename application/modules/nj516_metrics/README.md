# Метрики витрины (nj516_metrics)

Внутренняя админ-панель `/nj516/admin`. Считает обезличенные просмотры публичных
страниц сервисов, группирует по дню, группе, четырём типам источника и гостям/вошедшим.

Данные — только дневные суммы в `nj_516_views`, срок хранения 400 дней. Нет
идентификаторов посетителей, cookie ID, IP, сохранённого user-agent, полного referer,
URL-параметров или поисковых фраз. Публичной API для просмотра агрегатов нет.

Проверки: `php tests/mini_runner.php MetricsService`; миграции —
`php bin/console db:migrate`; очистка — `/nj100/cleanup`.
