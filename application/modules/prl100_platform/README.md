# prl100_platform — платформенная обвязка

Модуль-«рама»: без собственного публичного сервиса, держит общие экраны платформы.

## Состав

* `/dashboard` — рабочий стол: карточка пользователя, кликабельные метрики,
  статусы сервисов, «Быстрый старт» (без «Быстрых ссылок» — решение владельца).
  Внимание: `last_login` — INT epoch (форматирование epoch-безопасное, AGENTS §2.13).
* `/prl100/update` — админ-кнопка деплоя (пинок `bin/deploy.sh --migrate` через
  `/update/kick/<SITE_UPDATE_TOKEN>`); ответ JSON, повторный пинок безопасен (flock).
* `Task/Module/Scaffold.php` — генератор скелета нового модуля
  (`make new-module id=… slug=… name="…"`).

## Особенности

* Манифеста в каталоге нет (не сервис) — намеренно.
* Шаблон у всех страниц — `template_tailwindcss.php` (меню prl110, шапка-поиск,
  колокольчик prl597).
