# Тестовые данные (модуль 627) — памятка для агентов

Генератор вымышленных, но алгоритмически корректных данных: ФИО, телефоны,
e-mail (домен example.test) и реквизиты организаций — ИНН (10 знаков), КПП,
ОГРН, СНИЛС с верными контрольными цифрами. Для QA-форм, интеграций и валидаторов.

- Страница: `/testdata`
- API: `GET /nj627/api/generate?t=company&n=3`

Без таблиц и очередей. Алгоритмы контрольных цифр — в
`classes/Service/Nj627/Testdata.php`; JS — зеркало в `views/627/script.php`.

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj627_Testdata` (`generate`, `one`, `inn10`, `kpp`, `ogrn`, `snils`, `validate_inn`, `validate_ogrn`).
- Точки HTTP: `/testdata` (страница), `GET /nj627/api/generate`.
- Данные вымышленные, но контрольные цифры ИНН/ОГРН/СНИЛС — корректные (для QA).
- JS в `views/627/script.php` — зеркало сервиса; правки алгоритмов дублировать.
- Манифест: `config/nj_module.php` (slug `testdata`, группа «Разработчику»).
