# nj520_poll — Быстрые опросы (Ask 2 Vote)

- Создание: `/poll` → короткая ссылка `/p/<code>`
- Голосование: один голос с одного браузера (`voter_key` = `Visitor::uid()`)
- Результаты (числа и полоски) открываются после своего голоса; в закрытом опросе видны всем
- Ссылка на опрос с QR-кодом — на самой странице `/p/<code>`
- API: `GET /nj520/api/stats/<code>` (пока результаты скрыты — отдаёт `hidden:true` без вариантов)
- Таблицы: `nj_520_polls`, `nj_520_options`, `nj_520_votes`

Инструкции для агента — см. `AGENTS.md` рядом.
