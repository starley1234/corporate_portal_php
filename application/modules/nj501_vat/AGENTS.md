# nj501_vat — Калькулятор НДС — памятка для агентов

Публичный сервис N2J: выделить/начислить НДС по ставкам 2026 (22%, 20%, 10%, УСН 7%/5%, 0%).

- Страница: `/vat` (share-ссылки `?a=10000&r=22&m=extract`)
- API: `POST /nj501/api/calc`, `GET /nj501/api/rates` (JSON, публичный)
- Таблиц/воркеров нет; вся математика — в `Service_Nj501_Vat` (копейки, half-up)
- JS в браузере — зеркало сервиса для мгновенного пересчёта

## Правила для агента

Первый публичный сервис N2J. Stateless: **без БД, без очередей, без воркеров.**

## Контракт
- Класс-истина: `Service_Nj501_Vat` (чистые функции, суммы в **копейках**, округление half-up).
- Страница: `Controller_Nj501_Vat` → `/vat` (SEO: title/meta/FAQ schema.org).
- API: `Controller_Nj501_Api` → `POST /nj501/api/calc` `{amount, rate, mode}`, `GET /nj501/api/rates`. Публичный, без авторизации.
- Ставки: 0, 5, 7, 10, 20 (до 2026), **22 (с 2026)**. Выделение — расчётные `r/(100+r)`.
- JS-зеркало: `views/501/script.php` — инлайн `<script>`, подключается в конце
  вьюхи `/vat` и на главной (мини-демо). Отдельных HTTP-запросов за статикой нет.
  **При изменении формул менять PHP и JS вместе** и прогонять `tests/Unit/VatServiceTest.php`.

## Не делать
- Не добавлять таблицы/воркеров — не для этого модуль.
- Не хранить историю расчётов на сервере (только localStorage пользователя).
- Не редактировать `modules/` и `system/` (фреймворк Konine) — это не наш `application/modules/`.
- **Файлы статики не класть внутрь модуля** (`public_html/` внутри `application/modules/njXXX/`
  тут не публикуется — будет 404). Инлайн-скрипты — исключение: они живут во вьюхах модуля.
  Библиотеки и крупные файлы — в корневой `public_html/assets/` (`vendor/` — сторонние).
