# Подписи и реквизиты PDF (nj636_pdfsign)

Добавляйте должность, ФИО, дату и другие реквизиты поверх документа, считайте
и убирайте визуальные подписи — без установки программ. Всё выполняется на
сервере чистым PHP поверх движка nj634 (шрифт с кириллицей, ресурсы страниц
сохраняются).

## Что умеет

- **Наложить реквизиты** — построчный блок (по строке на поле), позиция в углу
  или по центру, страница: последняя / первая / все; подчёркивание.
- **Посчитать подписи** — эвристика: число /Annots + текстовые маркеры подписи.
- **Убрать подписи** — вырезать визуальные аннотации, не трогая текст.

## Безопасность

| Угроза | Мера |
|---|---|
| Command injection | shell не используется: наложение — чистый PHP (nj634) |
| Загрузка мусора | `is_uploaded_file`, магия `%PDF-`, лимит 15 МБ, отказ от шифрованных файлов |
| DoS | rate limit по IP в БД (мин/час) через `Service_Nj100_Ratelimit` |
| Утечка | файлы не покидают сервер и не публикуются |

## Сохранение в БД

`nj_636_runs` — история операций (kind: stamp|count|strip, сводка JSONB).

## API

```bash
# наложить реквизиты
curl -F 'file=@document.pdf' -F $'lines=Директор\nИванов И.И.\n23.09.2026' \
     -F 'pages=last' -F 'pos=bl' /pdf-sign/api/stamp -o signed.pdf

# посчитать подписи
curl -F 'file=@document.pdf' /pdf-sign/api/count

# убрать визуальные подписи
curl -F 'file=@document.pdf' /pdf-sign/api/strip -o clean.pdf
```
