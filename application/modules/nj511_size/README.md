# Подбор размера по меркам (`nj511_size`)

`/size` подбирает ближайшую справочную маркировку для женской/мужской/детской одежды, обуви, перчаток и колец.

- Источник данных — `config/nj511_size.php`.
- Страница хранит только текущую мерку и категорию в URL; API — `POST /nj511/api/convert`, справочник — `GET /nj511/api/categories`.
- Таблицы RU/EU/US и буквенные обозначения ориентировочные. У брендов, моделей и стран посадка отличается; перед покупкой проверяйте таблицу продавца.
- Нет БД, очередей, внешних API и хранения персональных мерок.
