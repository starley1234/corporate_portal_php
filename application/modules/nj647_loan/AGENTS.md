# Кредит и ипотека (модуль 647) — памятка для агентов

Публичный сервис N2J (группа «Финансы»): ежемесячный платёж, переплата и
полный график по кредиту или ипотеке. Два типа платежа (аннуитетный и
дифференцированный), досрочные погашения с выбором «сокращать срок» или
«уменьшать платёж», обратный расчёт «какой кредит потянет такой платёж».

## Контракт

- Страница: `/loan?sum=5000000&rate=18&term=20&term_unit=years&type=annuity&extra=10000&extra_mode=term&start=2026-10-04`
  (`full=1` — раскрыть весь график, по умолчанию раскрыт первый год).
- API: `GET|POST /nj647/api/calc` → `{ok,payment,total,interest,interest_pct,
  months_real,end,saved,…}`; `schedule=1` добавляет массив `schedule` (до 600
  строк, поэтому по умолчанию его нет). `GET /nj647/api/capacity?payment=&rate=&term=`
  → максимальная сумма кредита.
- Ошибка ввода — HTTP 422 и `{ok:false,error:"…"}` с человеческой причиной.
- Сервис: `Service_Nj647_Loan` (`calculate`, `annuity_payment`, `capacity`,
  `parse_number`, `fmt`, `term_words`, `add_months`, `types`, `extra_modes`).
- Таблиц, миграций, очередей и воркеров нет; числа пользователя не сохраняются.

## Правила для агента

- **Месяц здесь — это 1/12 года, а банк считает проценты по дням.** Расхождение
  с банковской выпиской заложено и честно описано на странице и в этой памятке.
  Не «чинить» его подгонкой коэффициентов: либо считаем по дням целиком (новая
  версия метода + тесты на високосный год), либо оставляем как есть.
- **Досрочное погашение сравнивается с тем же кредитом без него.** Экономия
  (`saved`) — разница двух прогонов `_simulate()`, а не формула «на глазок».
  Поэтому `calculate()` при `extra > 0` считает график дважды; это дёшево.
- «Уменьшать платёж» пересчитывает аннуитет от остатка на **оставшееся по
  исходному сроку** число месяцев — срок при этом не меняется. «Сокращать срок»
  оставляет платёж постоянным. Перепутать режимы = соврать про экономию.
- Последний платёж гасит ровно остаток: лишнего с заёмщика не берём, остаток
  не уходит в минус (в `_simulate()` ветки `>= $balance`).
- Полос прогресса на странице нет (корневой AGENTS.md, п. 10): доли — числами.
- Логика только в сервисе; JS на странице — единственная кнопка «ссылка на
  расчёт», зеркала формул в браузере НЕТ и заводить его не нужно.
