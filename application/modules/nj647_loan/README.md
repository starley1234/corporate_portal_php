# nj647_loan — Кредит и ипотека

- Страница: `/loan` — платёж, переплата, график по месяцам и годам
- Типы платежа: аннуитетный (равные платежи) и дифференцированный (убывающие)
- Досрочное погашение: сокращать срок или уменьшать платёж — с расчётом экономии
- API: `GET|POST /nj647/api/calc` (`schedule=1` — весь график), `GET /nj647/api/capacity`
- Таблиц и очередей нет: чистый расчёт, данные не сохраняются

Инструкции для агента — см. `AGENTS.md` рядом.
