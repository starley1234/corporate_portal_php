# nj514_translit — транслитерация — памятка агенту

Публичный stateless-конвертер `/translit`: русский ↔ латиница по таблице МВД для загранпаспорта, ГОСТ 7.79-2000 система Б и упрощённой записи ICAO/MRZ.

## Контракт
- `Service_Nj514_Translit::convert(text, standard, direction)` — PHP-истина; `standards()` отдаёт метаданные и карту.
- Таблицы, описания и ссылки — `config/nj514_translit.php`; JS использует эти же данные из SSR.
- API: `POST /nj514/api/convert` `{text, standard, direction}`, `GET /nj514/api/standards`.
- Направления: `to_latin`, `to_cyrillic`; стандарты: `passport`, `gost_b`, `icao`.
- Верхний предел — 4 000 символов.

## Правила
- Модуль работает локально, не записывает текст в URL, cookies, localStorage, аналитику или серверную историю.
- Обратное преобразование паспортной/ICAO-таблицы неоднозначно: `E` объединяет Е/Ё/Э, `I` — И/Й. Возвращать список вариантов и сохранять предупреждение.
- ГОСТ B использует `ц → c перед e/i/y/j, иначе cz`, а также апострофы для твёрдого/мягкого знаков, ы и э; не заменять упрощённой «английской» схемой.
- ICAO-режим выводит заглавные буквы, пробел заменяет на `<`; явно предупреждать, что это не генератор полной строки MRZ.
- При изменении таблицы обновить `tests/Unit/TranslitServiceTest.php` и `tests/Js/translit_parity.mjs`.
