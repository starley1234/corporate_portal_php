# Транслитерация (`nj514_translit`)

`/translit` преобразует русский текст в латиницу и обратно тремя таблицами: для загранпаспорта МВД, ГОСТ 7.79-2000 (система Б) и упрощённым ICAO/MRZ-совместимым видом.

- Таблицы и ссылки на первоисточники: `config/nj514_translit.php`.
- API: `POST /nj514/api/convert`, справка `GET /nj514/api/standards`.
- Текст не попадает в адрес страницы, cookie, localStorage или журнал расчётов; встроенный лимит — 4 000 символов.
- Обратный разбор паспортной/ICAO-записи неоднозначен (например, латинская E может означать Е, Ё или Э). Для официального имени сверяйтесь с документом.
