# nj648_timezone — Созвон по часовым поясам

- Страница: `/timezones` — текущее время участников и сетка суток с рабочими окнами
- Участник — город из справочника (`moscow`) или зона IANA (`Asia/Tokyo`)
- API: `GET /nj648/api/now`, `GET /nj648/api/slots`, `GET /nj648/api/cities`
- Справочник городов и рабочий день по умолчанию — `config/nj648_timezone.php`
- Таблиц и очередей нет: чистый расчёт по базе часовых поясов PHP

Инструкции для агента — см. `AGENTS.md` рядом.
