# AGENTS.md — nj100_platform (CLI-инструменты платформы)

> Памятка агенту. Общие правила платформы — в корневом /AGENTS.md.

## Назначение
Служебные CLI-задачи для разработки и эксплуатации: инвентаризация модулей,
генератор скелетов новых модулей, диагностика окружения. Всё, чем пользуются
агенты и разработчики из консоли.

## Состояние
- Готовность: рабочий.

## Ключевые классы
| Класс | Роль |
|---|---|
| `Task_Module_List` | `bin/console module:list [--json=1]` — таблица модулей: регистрация, AGENTS.md, миграции, классы |
| `Task_Module_Scaffold` | `bin/console module:scaffold --id=401 --slug=tasks --name="Задачи"` — скелет модуля nj401_tasks (перенесён из legacy erp218) |
| `Task_Dev_Doctor` | `bin/console dev:doctor` — PHP/ext/`.env`/каталоги/БД/миграции/очередь/документация модулей |
| `Service_Nj100_Ratelimit` | **общий rate limiter**: `client_ip()` (XFF), `window_counts()` (минута/час по таблице владельца), `allowed()`, `limit_text()`. Пороги остаются у модуля-владельца. Используют nj633/nj634 — новые сервисы должны брать отсюда, не копировать |

## Не трогать / подводные камни
- Имена задач (`module:list`, `module:scaffold`, `dev:doctor`) — контракт
  с Makefile (`make modules`, `make new-module`, `make doctor`). Не переименовывать.
- Scaffold не перезаписывает существующие файлы и создаёт модули ТОЛЬКО njXXX.
