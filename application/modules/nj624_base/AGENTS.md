# Системы счисления (модуль 624) — памятка для агентов

Перевод между двоичной, восьмеричной, десятичной и шестнадцатеричной системами
счисления и побитовые операции (И, ИЛИ, искл. ИЛИ, НЕ, сдвиги), работающие над
текущим значением в поле.

- Страница: `/base`
- API: `GET /nj624/api/convert?from=16&to=2&value=ff`, `GET /nj624/api/bitop?op=and&a=12&b=3`

Без таблиц и очередей (модуль stateless). Бизнес-логика — в
`classes/Service/Nj624/Base.php`; JS в `views/624/script.php` — зеркало.

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj624_Base` (`bases`, `is_valid`, `convert`, `bitop`, `_fmt_bin`).
- Точки HTTP: `/base` (страница), `GET /nj624/api/convert`, `GET /nj624/api/bitop`.
- Арифметика битовых операций — 32-битная (PHP int/JS `|`); в UI и сервисе одинаково.
- JS в `views/624/script.php` — зеркало сервиса; правки логики дублировать в обе стороны.
- Манифест каталога: `config/nj_module.php` (slug `base`, группа «Разработчику»).
