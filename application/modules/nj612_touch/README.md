# Серии касаний (nj612_touch)

Первое письмо и вежливые follow-up по компании — одним сценарием.

- Создаёте серию: компания, контакт, ваш оффер, тон, число шагов (до 4);
- ИИ пишет черновик каждого шага, следующий шаг ссылается на предыдущие письма;
- Отправка — по кнопке (или авто, если включено), пауза между шагами ~4 дня;
- Ответ контакта останавливает серию сам — статус `answered`.

## Как это устроено

```
серия → очередь nj120 (nj612.touch) → LLM-черновик шага → /touches/api/step →
отправка (SMTP сайта) → пауза 4 дня → следующий шаг ... → ответ → стоп
```

Ответ контакта определяется по разобранным входящим (nj610): если контакт
писал после последней отправки — серия останавливается и приходит уведомление.

## Админка

`/nj612/admin` — все серии и их таймлайны (роль admin).
