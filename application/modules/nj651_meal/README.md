# nj651_meal — Калории по фото тарелки

- Страница: `/meal` — снимок тарелки, разбор в фоне, результат на `/meal/<id>`
- Что получает человек: блюда, вес порций, калории и БЖУ, доля своей суточной
  нормы (формула Миффлина — Сан-Жеора) и остаток калорий на день
- Профиль (пол, вес, рост, возраст, активность, цель) живёт в адресе:
  `/meal?sex=m&weight=80&height=180&age=35&activity=medium&goal=loss`
- Создание разбора — после входа (решение владельца 06.10.2026, «как опросы»):
  гость видит плашку входа, API отвечает 401 + `login`; профиль и расчёт
  нормы остаются публичными, история следует за аккаунтом
- API: `POST /meal/api/photo`, `GET /meal/api/status`, приватный
  `GET /meal/api/preview` (только владелец), `POST /meal/api/photo_file`
  (для воркера), `POST /meal/api/worker_result`
- История «Мои тарелки»: компактные плитки с JPEG-превью до 320 px,
  кратким итогом КБЖУ и удалением своих завершённых разборов
- Канал очереди `nj651.meal`, воркер `workers/n2j_workers/handlers/nj651_meal.py`
- Таблица `nj_651_runs` (чистка через 90 дней); исходный кадр удаляется после
  разбора, приватная миниатюра хранится вне docroot до 90 дней, каталог/файл
  имеют права 0700/0600 и включены в закрытый backup (0700/0600)

Инструкции для агента — см. `AGENTS.md` рядом.
