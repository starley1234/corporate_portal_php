# CSV ↔ JSON (модуль 632) — памятка для агентов

Честный CSV-парсер с кавычками (RFC 4180) и конвертер в JSON (массив объектов
с заголовками из первой строки) и обратно (JSON-массив → CSV с экранированием).
Разделители: запятая, точка с запятой, табуляция, вертикальная черта.

- Страница: `/csv`
- API: `GET /nj632/api/convert?mode=csv2json&data=a,b%0A1,2`

Без таблиц и очередей. Логика — в `classes/Service/Nj632/Csv.php`,
JS — зеркало в `views/632/script.php`.

## Правила для агента

- Модуль **stateless**: таблиц, миграций, очередей нет.
- Сервис: `Service_Nj632_Csv` (`parse`, `to_json`, `from_json`, `delimiters`, `_cell`).
- Точки HTTP: `/csv` (страница), `GET /nj632/api/convert`.
- CSV — RFC 4180 (кавычки, «»); первая строка — заголовки.
- JS в `views/632/script.php` — зеркало сервиса; разделитель из select.
- Манифест: `config/nj_module.php` (slug `csv`, группа «Конвертеры»).
