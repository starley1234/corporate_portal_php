# Каталог и навигация PRL

Сохранена оболочка исходной дизайн-системы: адаптивная левая панель, чипы
текущего раздела в шапке, мобильная шторка, тёмная тема, профиль и колокольчик.
Компоненты — `.tools/tailwind/input.css` и DESIGN-SYSTEM.md.

Каталог строится из подключённых `config/prl_module.php` через Manifest и
`Service_Prl110_Catalog`. Для карточки нужны title/href; видимость определяется
status/audience. `audience=admin|auth` — фильтр UI, а не авторизация маршрута.
Реальный доступ проверяют контроллер и сервисная policy.

Меню больше не закрепляет три сервиса прежнего публичного сайта. Оно показывает
доступные текущему пользователю модули из манифестов. Инструменты платформы
собраны на `/admin`; `set_module_nav()` добавляет чипы текущего модуля.
Планируемые 50 сервисов не выдаются за работающие ссылки: главная показывает
только направления развития, каталог — только реальные манифесты.

При готовности бизнес-модуля: добавить href/group/icon/short/audience в его
манифест, реализовать policy, пройти тесты и обновить статус плана. Ядро
навигации для добавления очередного сервиса править не требуется.

Глобальный поиск `/search/api` и JSON каталога требуют сессию. Технический
RAG-кэш исключён из общего поиска. Объектный поиск корпоративных данных должен
фильтровать организации/доступ до выполнения запроса и перед отображением.
