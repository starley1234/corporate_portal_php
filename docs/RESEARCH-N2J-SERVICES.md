## 1. Резюме (TL;DR)

1. **Модель «хаб онлайн-инструментов» жизнеспособна**: calculator.net, omni
   calculator, unitconverters.net, Smallpdf, TinyPNG собирают огромный
   поисковый трафик годами (см. §3). Ключ — длинный хвост простых утилит +
   programmatic SEO.
2. **N2J — свободная аббревиатура** (устоявшихся значений нет) → бренд можно
   «зарядить» нужным смыслом. Лучшие прочтения: **«N-to-J: Numbers/Notes →
   Just-done»** и осмысленные расшифровки для отдельных сервисов (§2, §6).
3. **Первый сервис — Калькулятор НДС** (`nj501_vat`): вечнозелёный спрос,
   русскоязычная специфика, **ноль инфраструктуры** (без БД и воркеров),
   богатый UI, а налоговая реформа 2025–2026 (УСН 5/7%, ставка 22% с 2026)
   сделала большинство старых калькуляторов устаревшими — окно для SEO (§7).
4. Полный каталог из **60+ идей с приоритетами** — §5. Дорожная карта первых
   десяти модулей — §8.

## 2. Бренд N2J: как «зарядить» аббревиатуру

По базам аббревиатур устойчивого значения «N2J» нет — поле свободно. Цифра 2
читается как «to/ту», поэтому домен идеально ложится на схему **«X 2 Y»**
(преобразование). Это и есть ДНК бренда: *мы превращаем одно в другое — быстро,
бесплатно, без регистрации*.

| Прочтение | Смысл | Под какие сервисы |
|---|---|---|
| **Numbers → Just** | «Числа — в готовое» | калькуляторы, финансы, конвертеры единиц |
| **Notes → Journal** | «Заметки — в дневник/документ» | текстовые инструменты |
| **Null → JSON** | «из ничего — в структуру» | dev-инструменты, данные |
| **Need 2 Just(-do-it)** | «нужно — просто сделай» | общий слоган платформы |
| **New 2 Job** | «новичок в профессии» | карьерные/зарплатные калькуляторы |

**Слоганы:** «N2J — нужно? Значит, сделано», «Need 2 Just do it», «Из N в J за
два клика». Tone of voice: быстрый, точный, без лишних слов (совпадает с
принципом лаконичности платформы).

> Рекомендация: не выбирать ОДНУ расшифровку навсегда. Использовать схему
> «X→Y» как систему именования групп сервисов — она масштабируется и
> усиливает домен (Numbers 2 JSON, Note 2 JSON, Norm 2 Joke...).

## 3. Что говорит рынок

### 3.1 Мировой опыт (валидация модели)

* Подборки «самых полезных сайтов» стабильно включают утилиты: Smallpdf
  (PDF), TinyPNG (сжатие картинок), timeanddate (время/календари),
  UnitConverters.net (единицы), XE (валюты), Wolfram|Alpha (вычисления) —
  [ZenixTools, «25 Most Popular Utility Websites»](https://www.zenixtools.com/blog/most-popular-utility-websites).
* Среди калькуляторных сайтов лидеры — **агрегаторы**: Omni Calculator
  (3000+ калькуляторов), Calculator.net, Calculator Soup —
  [mycalcul.com, «Top Calculator Websites 2025»](https://mycalcul.com/blog/best-calculator-websites-2025).
  Урок: ценность растёт с широтой каталога и перелинковкой.
* Самые востребованные dev-утилиты (из каталога в 600+ инструментов):
  JSON-форматтер/валидатор, UUID, генератор паролей, QR-генератор, Lorem
  Ipsum, MD5, color picker —
  [TestMu AI (LambdaTest)](https://www.testmuai.com/free-online-tools/).
* Рост таких площадок — классический **programmatic SEO**: тысячи страниц
  «<задача> онлайн», каждая — один инструмент + FAQ + перелинковка
  ([обзор pSEO-инструментов](https://www.shoutmeloud.com/programmatic-seo-tools.html)).

### 3.2 Русскоязычный сегмент

* Инструмент проверки спроса №1 — Яндекс Вордстат; перед запуском каждого
  сервиса проверяем частотность по нему
  ([обзор методов](https://clevertips.ru/seo/top-zaprosy-v-yandeks-i-google)).
* Налоговая реформа сделала тему НДС «горячей» на 2025–2026:
  * с 2025 УСН-щики стали плательщиками НДС: пониженные ставки **5% и 7%**
    (расчётные 5/105 и 7/107) — [1С](https://torg.1c.ru/news/kak-uproshchentsu-schitat-i-platit-nds-s-2025-goda/),
    [Гарант](https://www.garant.ru/1c-wiseadvice/guide/nds-na-uproshchenke-s-2025-goda/);
  * в 2026 границы пересмотрены: освобождение при доходах до **20 млн ₽**,
    5% — до 272,5 млн, 7% — до 490,5 млн, выше — общая ставка
    ([Контур.Эльба](https://e-kontur.ru/enquiry/2384/stavki-nds-na-usn));
  * **общая ставка НДС с 2026 — 22%** (была 20%), льготная 10% сохраняется
    ([Контур.Эльба](https://e-kontur.ru/enquiry/2384/stavki-nds-na-usn)).
  → Большинство старых калькуляторов в выдаче считают по ставке 20% и не
  знают про 5/7/22. Свежий калькулятор с корректными ставками 2026 + формулы
  + FAQ — реальное SEO-окно.
* Предпринимательская аудитория (ИП/бухгалтеры) — коммерчески ценная,
  возвращающаяся: счёт-фактуры, авансы, проверка контрагентов — регулярно.

### 3.3 Выводы для N2J

1. Строим **хаб утилит с длинным хвостом**: каждый сервис = отдельная страница
   с H1 «<Задача> онлайн», формулами, FAQ (schema.org FAQPage) и перелинковкой.
2. Приоритет — сервисы: (а) с устойчивым спросом, (б) без внешних API/воркеров
   на старте, (в) где мы можем дать **свежесть/локальность** (RU-налоги,
   единицы, документы), (г) с повторными визитами.
3. Каждый сервис — модуль `nj5XX_slug`: изолированно, лаконично, с общими
   UI-компонентами платформы (сайдбар, тёмная тема, тосты).

## 7. Первый сервис: Калькулятор НДС (`nj501_vat`)

### Почему он

| Критерий | Оценка |
|---|---|
| Спрос | вечнозелёный: счёт-фактуры, авансы, УСН — ежедневно у сотен тысяч ИП/бухгалтеров |
| Окно SEO | реформа 2025–2026 (ставки 5/7/22, новые пороги) — старые калькуляторы устарели |
| Инфраструктура | **0 ₽**: без БД, без воркеров, без внешних API — чистые функции |
| Сложность | минимальная (формулы на копейках), весь риск — в аккуратном UI |
| UI-витрина | сегмент-контрол, переключатель, живой ввод, карточки результатов, копирование, share-ссылка, история, FAQ — покажет «зоопарк» элементов сразу |
| Синергия | сосед по каталогу — «Сумма прописью» (№28) сядет рядом в §«Финансы» |

### Спека модуля `nj501_vat`

**Формулы** (все расчёты в копейках, округление half-up до копейки):
* Начислить НДС сверху (сумма S без НДС): `НДС = S × r/100`; `Итого = S + НДС`
* Выделить НДС из суммы (S с НДС): `НДС = S × r/(100+r)`; `Без НДС = S − НДС`
* Расчётные ставки: 22/122, 20/120, 10/110, 7/107, 5/105 — покрываются той же формулой.
* Ставки-селектор: **0, 5, 7, 10, 20, 22** (20 — «до 2026», с подписью).

**UI-элементы (витрина):**
1. Поле суммы с живым форматированием `1 234 567,89` (ввод цифрами, пробелы-разделители).
2. Сегмент-контроль ставок `0 · 5 · 7 · 10 · 20 · 22` (+ бейдж «УСН» на 5/7, «2026» на 22).
3. Переключатель режима «НДС в сумме ⇄ Начислить сверху».
4. Чипы быстрых сумм (1 000 / 10 000 / 100 000 / 1 000 000 ₽).
5. Три карточки результата (НДС / Без НДС / Итого) с анимацией числа.
6. Таблица-расчётка с формулой («S × 22/122 = …») — доверие + SEO-текст.
7. Кнопки: «Копировать результат», «Скопировать ссылку» (состояние в URL
   `?a=10000&r=22&m=extract`), «Поменять» (extract ⇄ add с сохранением итога).
8. История последних 8 расчётов (localStorage) — чипы, очистка.
9. FAQ-блок с schema.org/FAQPage: формулы, ставки 2026, авансы, УСН 5/7.
10. Тосты, тёмная/светлая тема, сайдбар платформы — из шаблона.
