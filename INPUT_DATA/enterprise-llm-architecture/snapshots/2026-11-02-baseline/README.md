# Снимок архитектуры 2026-11-02 (baseline)

Состояние **до** добавления пайплайн-платформы подразделения (вкладки TO-BE 13–14): AS-IS v1.7.x (15 вкладок) и TO-BE v2 (12 вкладок).

- Посмотреть: открыть `architecture.html` в браузере (файл самодостаточный, работает офлайн).
- Git-тега `arch-baseline-2026-11-02` в репозитории нет: история — один сквинченный коммит,
  поэтому база сравнения — сам снимок (содержимое `arch/` на момент снимка не восстановить,
  но собранная модель — да).
- Сравнить с текущим: `npm run arch -- diff snapshots/2026-11-02-baseline`.
  Diff идёт по модели (`architecture.json`), поэтому показывает изменения в узлах, связях,
  текстах и таблицах; координаты в модель не входят.
- Новые снимки — `npm run arch -- snapshot <имя>`; класть в соседние папки `snapshots/YYYY-MM-DD-имя/`.
- Сам снимок (`architecture.html`, `architecture.json`) не редактировать.
