# Тесты воркеров

Зеркалят `prx_workers/`: `runtime/` — очередь, сторожа, конфиг, реестр каналов и логи;
`handlers/<пакет>/` — обработчики каналов (владелец тот же, что у пакета);
`clients/` — общие клиенты (LLM, OCR); `mock/` — мок-серверы.

Запуск из корня репозитория: `PYTHONPATH=workers python3 -m pytest workers/tests -q`.
